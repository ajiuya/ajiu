# 聊天内文件预览

在聊天中点击 AI 发来的文件附件，或点击回复中的本地文件链接，即可在应用内打开预览。预览覆盖在聊天上层，不会把原聊天页面销毁；返回或关闭后，可继续原来的阅读位置。

图片和音视频沿用已有的图片查看器与播放器。带行号的代码链接仍可直达编辑器，普通文件预览右上角菜单也提供适用的「编辑」入口。

## 可以查看什么

| 文件 | 预览方式 |
| --- | --- |
| Markdown | 渲染标题、表格、代码和本地图片 |
| 文本、代码、SVG 源码 | 只读文本，可选择复制 |
| JSON | 内容完整且有效时格式化；否则显示原文 |
| CSV、TSV | 表格预览，支持带引号和换行的单元格 |
| HTML | 应用内网页，允许本地脚本与授权目录内的关联资源 |
| PDF | 保留文档版式，滚动时按可见页加载 |
| ZIP、JAR、AAR | 列出条目名称与大小，不自动解压或运行 |
| APK | 显示可读取的应用信息；点击「安装应用」才进入系统安装流程 |
| Office、其他格式 | 显示文件信息，可另存、分享或选择外部应用打开 |

预览不保证设备能解码每一种图片、音视频或 PDF。损坏、加密、不支持的格式以及超出限制的文件会显示无法预览，仍可根据实际可用情况选择外部打开。

## 文件操作

右上角菜单提供「分享」「另存为」「外部打开」，支持的文本格式还可进入编辑器。查看本身不会修改文件，保存时由你选择目标位置，安装 APK 也不会自动批准系统权限。

Markdown 或网页中的同目录文件链接可以继续在预览中打开，返回键先回到上一份文档，再关闭预览。外部网页链接会先要求确认，不会因网页脚本或重定向自动启动其他应用。

## 本地文件与 SSH

打开文件时会固定当前工作区、容器配置或 SSH 连接。切换这些环境后，旧预览会失效，不会继续读取新环境中的同名文件。

附件的临时副本还存在时，可以先查看缓存；这类缓存只代表当前文件，不能据其临时目录读取其他附件。需要关联图片、CSS 或脚本时，可以选择「从当前环境读取」，确认文件所属的环境后重新加载。

历史附件没有保存完整的服务器和容器身份。缓存已被系统清理时，应用不会自动搜索其他服务器的同名文件；请切换到正确环境，再确认重新读取。

SSH 的 PDF、压缩包等需要先取得完整的有界临时副本，首次打开较大的文件会等待。关闭预览会取消该预览的读取和临时任务，不会断开其他终端共用的 SSH 连接。

## 网页与资源边界

HTML 预览使用独立的网页实例，不提供 AI 工具或原生应用的脚本接口。默认只允许授权目录内的文件资源，不自动加载外部网络资源；依赖在线 CDN、远端字体或联网接口的网页可能无法完整显示。

相对路径必须留在文档授权目录内。越界路径、指向目录外的符号链接和失效资源会被拒绝，不会扩大到整个设备或服务器文件系统。较旧的系统 WebView 缺少必要的安全能力时，网页可能无法预览，请更新 Android System WebView 或使用外部打开。

这不是完整浏览器或操作系统级沙箱，不要把来自第三方的脚本当作可信代码。

## 预览范围与限制

- 单文件预览与临时副本上限为 100 MiB。
- 文本预览最多读取 2 MiB；表格最多 200 行、50 列；压缩包最多列出 2,000 个条目。
- 超出展示范围会明确提示，不会把截断内容冒充完整文件；完整文件可按实际大小限制分享、另存或外部打开。
- PDF 不会先把整份文档全部解码为图片；单页与缓存均有预算，异常超长页面会缩小显示。
- 预览关闭后不会恢复脚本、自动播放媒体、重新执行工具或重放安装操作。
