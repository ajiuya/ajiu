# 终端

AiCode 内置终端，本地模式连接手机上的 Linux 容器，远程模式连接 SSH 服务器。PRoot 和 SSH 按各自权限安装工具、编译或运行服务；**新建 v2 CHROOT 的普通终端以 guest UID 0 运行，guest rootfs 可写**，可以在任务范围内使用 `apt` 等工具维护 guest 软件包，不再是 App UID 的只读系统。App 控制端身份仍核验，正常软件包维护使用受限 capabilities，不授予 `CAP_SYS_ADMIN`／`CAP_SYS_PTRACE`；hostRO 配置、DNS 等宿主绑定仍只读，详见[容器与镜像](/guide/container)。

CHROOT 没有 PID／user namespace 隔离，不是安全沙箱。guest 自己的 `/etc`、`/usr`、`/var` 不等于宿主系统文件；任意 root 命令仍可能改变共享工作区的文件属主，不能用递归 `chown` 自动修复。

从聊天页顶部标题栏的「终端」进入。点左上角返回按钮回到聊天页，返回过程中重复点击不会继续退出聊天页。返回不会关闭终端标签。

## AI 如何选择命令工具

AI 会按任务是否耗时、是否需要保留会话来选择执行方式：

- **Bash**：用于短时、一次性的命令，例如查询状态、快速检查；执行结束后返回结果。
- **终端**：用于构建、安装依赖等耗时任务，开发服务器等常驻进程，以及需要持续输入的交互操作。你可以在终端标签里查看输出和继续操作。

对于会自行结束的耗时任务，AI 可以开启完成通知，任务结束后再继续处理结果；常驻服务和交互程序则按需查看输出、发送输入或停止进程。

## 标签管理

终端支持多个标签同时存在，顶部标签栏可以横向滑动，切换时当前标签会自动滚动到可见位置。

- 标签名前的圆点表示状态：绿色是运行中，灰色是已结束。
- 点标签右侧的 × 关闭，点标签栏末尾的 + 新建。关掉当前标签后会自动切到相邻的一个。
- AI 执行命令时开启的终端也会出现在这里，你可以随时切过去查看它的运行情况。
- AI 为后台任务启用完成通知后，本地与远程 SSH 模式都会在任务结束时把退出码和末尾输出送回发起任务的会话；AI 正忙时会在处理过程中或本轮结束后收到通知。停止当前 AI 回复时，待送的完成通知会保留并在本轮收尾后补送。完成通知通过独立通知通道送达，不进入用户消息队列。
- 聊天中的后台任务通知只显示终端标签标题、完成状态和退出码，不展示命令或工作区路径；完整执行详情仍可在终端查看。

后台完成检查在没有新输出时复用已有内容，不通过缩短保留历史或放慢检测来节省资源。对于启用完成通知、已经确认结束的后台命令，应用会清理仍挂住的终端后端，保留退出码与输出供回看；普通交互标签与未启用完成通知的常驻服务不会因此被关闭。

### CHROOT 标签与清理

CHROOT 标签仍使用独立来源，用户新建标签与 AI 会话创建标签分别冻结配置摘要、实例、工作区和 Root 代际，不借用彼此的捕获。普通命令默认放行，冷启动按策略自动绑定，无需逐来源到设置中确认。实际新建标签、执行或重试可按需建立 Root 通道（`ensureRoot`），但 Root 总开关与真实系统 su 授权仍是前提；系统拒绝不视为可用，来源或通道为 UNKNOWN 时拒绝执行，旧捕获撤权后不可复用。

对 Root／Shizuku／本地 CHROOT，能确认宿主系统文件操作只读时默认 `ALLOW`；修改宿主或未知脚本、动态路径、交互输入等无法确认是否只读时先审批，实际只读的脚本也可能弹窗。可选「仅本次允许」（`ONCE`）或「本会话始终允许」（`ALWAYS_SESSION`）；后者覆盖本聊天 session、同一 tool、同一 source／identity 的全部后续宿主修改与不确定操作，包含不同命令和目标，不限当前命令，不跨工具、来源、身份或父子／其他会话。

向已有交互程序使用 `send`／`key` 送入内容，不能仅凭输入里含有 `cat` 等字符串就确认只读；无法确认是否修改宿主时先审批，同来源及身份的本会话授权可减少后续同工具输入的打断。判断是有限静态识别，不执行或打开脚本，不是运行时拦截；符号链接、`PATH` 和任意程序实际副作用不能保证，也不是命令沙箱。

新的宽授权仅存内存，进程重启清除；来源、真实身份或连接、Root 代际、Profile 配置内容或选择、实例变化后需重审。每次 Root／Shizuku 执行仍消费绑定完整命令的单次内部 permit，不能重放，也不为取得新 permit 另弹一次窗；宽授权不是无限 OS Root 权限。显式 `DENY`、Root 总开关、真实 OS 授权及 CHROOT UNKNOWN／清理限制不变。PRoot／SSH 的 `sudo`／`su`、适用高危命令与 `elevate` 仍保留原有精确完整命令会话授权；计划、插件内容启用与宿主能力、依赖准备及独立 CREATE／STOP／REMOVE 确认不取消，详见[工具授权](/guide/permissions)。

旧 AJIM v1 只读实例不自动迁移，也不以可写 root 模式运行。要使用可变 guest 系统与相应安全清理流程，应按容器页引导新建 v2 实例并明确激活；旧原生 REMOVE 的兼容能力不代表助手可以自动删除旧现场。查看状态与任务历史不自动重跑旧命令。

标签结束以真实进程结果为准，屏幕输出中的结束标记不能证明退出或清理。任务退出与清理分开显示：退出未知不代表信号 1、失败或成功；“清理待确认”及“清理结果未知”也不代表已经回收。关闭标签只停止该任务，不会顺带撤销其他任务仍有效的来源或许可。

## 任务历史

终端页右上角的「任务历史」可查看当前本地容器、工作区的已保存后台任务。首版仅记录 AI 启动且启用完成通知的本地长命令，不包含普通交互终端、常驻服务、插件终端或远程 SSH 标签。

- **运行中**：当前进程仍在管理此任务，展示最近成功保存的快照。
- **已结束**：应用已观察并保存退出码；退出码为 0 只说明命令正常退出，具体构建、测试或业务结果仍需核对输出和产物。
- **结果未知**：之前的进程已结束或失去跟踪，没有可靠的已保存退出结果。不能据此认定成功、失败或仍在运行，也不会自动重跑。

历史详情只读，可查看时间、独立历史 ID、退出码与已保存输出；打开历史不会启动容器或新终端。输出沿用有界快照，超出上限时保留首尾并标明截断，不是完整输出录制；最近尚未写盘的内容可能缺失。历史保存在本机应用私有目录，不随备份恢复。

AI 可使用独立的 `history_id` 读取其所属会话与当前本地工作区的记录；它与活终端 `tab_id` 不同，不能用于输入、快捷键或关闭进程。切换工作区、容器或执行后端不会把旧来源的记录交给新来源。历史不会自动补发完成通知、续跑模型、恢复旧审批或接管旧 PID。

## 输入与复制

点击终端区域获得焦点，即可直接输入。长按可以选择并复制输出内容。

## 辅助按键栏

手机键盘没有 Esc、Ctrl 和方向键，所以终端底部提供了一条可横向滑动的辅助按键栏：

- **控制键**：`ESC`、`TAB`、`CTRL`、`ALT`。Ctrl 和 Alt 按下后会高亮，再按字母键即组成组合键。
- **方向键**：上下左右，长按可以连续发送，用来快速移动光标。
- **常用组合**：`C-c` 中断当前命令、`C-d` 发送 EOF 或退出、`C-z` 挂起进程、`C-l` 清屏。
- **常用符号**：`|`、`~`、`/`、`-`、`_`、`>`、`:`、`$`、`"`、`'` 等，免去切换符号键盘。

## 外观设置

点终端页右上角的齿轮图标（或者从「设置 → 通用设置 → 终端设置」进入）可以调整：

- **配色主题**：默认「跟随应用」（自动匹配当前应用主题的深浅模式与背景色调），同时内置 GitHub Light 明亮主题与 Termius Dark、Dracula、One Dark、Monokai、GitHub Dark 五套经典暗色配色，选中立即生效，所有已打开的标签一起变。
- **字体大小**：5 到 22 之间调节，面板顶部有实时预览；也可以直接在终端区域双指捏合，和这里的取值是同一个。捏合时会按实际字号重新排列终端行列，高频调整会合并，松手后保存最终字号，不只是把画面放大。双指操作不会变成点击、长按或单指滚动；选中输出文字时不启动缩放。
- **字体**（**1.11.0 起**）：默认是 JetBrains Mono（无连字版本），`0` 和 `O`、`1` 和 `l` 区分得很清楚。也可以切换成系统等宽字体，或点「导入」从手机里选一个 `ttf` / `otf` / `ttc` 字体文件；导入的字体会出现在列表里，点字体标签上的 × 可以删除，删掉正在用的会自动回落到系统等宽。中文字符始终由系统字体补齐。字体只影响终端，不改变 AI 对话区。
- **光标样式**：方块、下划线、竖线三种。
