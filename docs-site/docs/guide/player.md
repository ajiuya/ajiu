# 内置播放器

播放器可以打开当前工作区的音视频、远程 SSH 文件和网络媒体直链，支持播放列表、选集、进度记忆、全屏和画中画。

## 打开播放器

- 从侧边栏底部点击「播放器」，进入完整控制页。
- 在文件树点击音视频文件，直接打开对应媒体。
- 点击聊天中已发送或工具返回的音视频附件，也可打开对应媒体。AI 返回附件本身不会启动播放器。
- 在播放器内选择设备上的媒体文件，或输入公网 HTTP／HTTPS 媒体直链。普通网页链接请用浏览器打开。

MP4、WebM、MP3、M4A、Ogg 等常见格式，以及 HLS（m3u8）和 DASH（mpd）可以交给播放器处理。能否实际解码取决于手机、媒体编码和 Android System WebView；文件扩展名出现在列表中，不代表设备一定支持该编码。

## 播放与选集

完整控制页可以调整进度、音量、倍速，切换顺序、单曲循环与随机播放，并管理播放列表。选集页保留所选线路的全部剧集，较长列表分段显示，不会只保留最前面的几集。

播放器会记住播放进度和部分播放设置。本地与 SSH 工作区的记录按项目环境区分，同名路径不会直接共用另一环境的播放记录；重新连接同一服务器和项目后可继续使用原进度。进度记录不代表媒体文件仍然存在，也不会自动恢复失效的连接。

## 在线影视目录

在播放器内打开影视搜索，输入名称或关键词，可筛选来源、翻页查看结果，再选择线路和剧集。失败来源会单独提示，可更换来源或重试。

这是联网查询，不包含预装的离线影视索引或终端工具包。没有网络时无法搜索；结果受来源可用性和当前内容影响，可能与旧版离线快照不同。部分来源不支持关键词搜索，仍可能支持已知条目的详情读取。搜索结果和播放地址由第三方提供，应用不保证一直可访问。

## 全屏、画中画与后台

- **全屏**：使用播放页的全屏入口；返回键先退出全屏，再返回上一页。
- **画中画**：系统和设备支持时，可从播放器菜单开启。画中画提供播放／暂停、上一首或上一集、下一首或下一集控制。
- **离开时画中画**：可在菜单中单独启用，能否成功进入取决于系统支持与权限状态。
- **后台播放**：默认关闭。开启后，通知和系统媒体面板提供控制；关闭后，离开前台且没有画中画时会暂停。

后台播放依赖仍存活的播放器页面；关闭播放器、从最近任务划掉应用或系统结束进程后，不保证继续播放。系统限制、厂商省电策略或 WebView 回收也可能中断播放。

## 本地与 SSH 文件

本地文件通过当前执行环境读取；SSH 文件首次播放需要先下载到手机临时副本，大文件会有较长等待，也会占用手机缓存空间。此过程不是 SSH 边下载边播放。关闭播放会话会释放它拥有的连接和临时副本。

切换工作区、容器配置、执行模式或 SSH 连接后，原会话会失效，不会继续读取新环境中的同名文件。请从当前文件树重新打开。网络播放可独立使用，不要求先启动容器或连接 SSH。

## 无法播放时

1. 确认地址是媒体直链，或文件仍存在于当前环境。网页、登录页面和需要额外鉴权的地址不能当作普通媒体直链使用。
2. 检查网络或 SSH 连接，远程大文件可等待首次副本下载完成。
3. 页面提示 WebView 不支持或渲染进程退出时，更新 Android System WebView，关闭后重新打开播放器。
4. 若只有某个媒体无法播放，尝试设备支持的编码或更换目录来源。应用不会自动安装额外解码工具。

网络媒体仅接受公网 HTTP／HTTPS 地址；本机、局域网及带用户名密码的 URL 会被拒绝。播放器当前支持直连：如果应用代理设置要求该地址走 HTTP／SOCKS 代理，请求会被拒绝。播放器不会自行绕过你设置的代理；需要联网播放或搜索时，请先在设置中明确允许相应地址直连。播放器不提供独立的外挂字幕选择界面。
