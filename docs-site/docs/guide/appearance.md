# 外观与语言

在「设置」首页点「外观主题」进入二级页面，集中调整主题、全局背景、聊天背景、聊天字号与聊天气泡。原有明暗模式、配色方案与莫奈取色均保留，原首页的全局背景入口移到此页。语言仍从设置首页单独打开底部选择窗口。

## 外观主题

页面中的主题区域保留三块：明暗模式、配色方案、莫奈取色。选择后立即生效并保存，可以留在页面中连续对比多套配色。

### 明暗模式

三选一：跟随系统、固定深色、固定浅色。

### 配色方案

四套预设，深浅两种模式各自配好：

- **默认蓝**：App 默认的蓝色调。
- **咖啡**：暖赤陶色 + 米白纸感底。
- **石墨**：中性冷灰，颜色干扰最小。
- **森林**：低饱和绿。

色块外圈是该主题的页面底色、内圈是主色，预览会跟随当前明暗模式变化。

Git 泳道色、日志级别色、diff 增删的红绿属于功能标识，不随主题变化，避免同一含义在不同主题下颜色不一致。代码编辑器的语法高亮与终端配色也是各自独立的设置。

### 莫奈取色

开启后从系统壁纸提取配色，上方所选的配色方案不再生效（色块变灰）。默认关闭。

需要 Android 12 及以上系统；低版本设备上开关不可用，描述会直接提示。壁纸调色板由系统生成，不同手机厂商的取色结果差异较大，效果不满意关闭即可。

## 交互动画

界面采用轻量、克制的交互反馈：按钮按下时轻微下沉，设置行以柔和底色回应；页面进入和返回保留方向，但位移更小。开关、标签滑块与折叠箭头使用接近的节奏，减少明显的拉伸和弹跳。

动画不会延迟按钮操作，也不改变滑动触发范围。长代码和持续输出不叠加整段高度动画；系统关闭或缩短动画时，界面按系统设置响应。手机底栏的原生拖拽与键盘避让保持不变。

会话进度点、待办进度点、工具状态和等待文字的循环装饰，只在相应界面可见且应用处于前台交互状态时播放。抽屉完全关闭或应用暂停时保留静态状态，不在隐藏位置持续闪动；重新显示后恢复。这只暂停展示动画，不会暂停模型、工具或后台任务。

## 自定义背景图

「设置 → 外观主题」中有「全局背景」与「聊天背景」两个独立入口，分别选择图片、调整透明度和移除，不会互相替换。

### 全局背景

保留原有全局水印行为，只移动设置入口：

- **选择图片**：从系统相册选一张作为全局水印，叠在页面内容上，不拦截触摸。它并非聊天专用，终端等页面也可能显示水印。
- **透明度**：滑块显示 0% 到 100%，实际不透明度映射到 0% 到 20%（即滑到 100% 相当于 20% 不透明度），保留原有的浅水印效果。默认实际不透明度为 15%（滑块 75%），拖动实时生效。
- **移除背景**：只移除全局水印，不移除单独设置的聊天背景。

### 聊天背景

仅在聊天内容区显示，不扩展到终端、Git、设置等其他页面，也不替代全局水印：

- **选择图片**：从系统相册选图后，应用会把副本保存到私有目录，后续显示不依赖相册的临时访问授权。
- **透明度**：滑块直接对应真实的 0%–100% 不透明度，0% 不可见、100% 完全不透明，默认 20%。这与全局水印最高实际 20% 的映射不同；背景在聊天内容后方，文字、按钮等仍在其上显示。
- **移除背景**：只移除聊天背景；如仍设置了全局水印，水印继续保留。

两类背景图的本机设置在重启后保留。图片本体与本机绝对路径**不随备份导出**，更换设备需要重新选图；聊天背景的透明度可随「应用设置」备份恢复，见[备份与还原](/guide/backup#应用设置与外观)。

## 聊天字号

在「设置 → 外观主题」的「聊天字号」区域拖动滑块，可调整到 **80%–140%**，默认 **100%**。下方示例会随拖动预览大小，松手后应用并保存。

- AI 正文、用户消息、思考内容，以及 Markdown 中的代码块和行内代码同步缩放。
- 菜单、按钮与其他操作控件的字体大小保持不变；代码编辑器与终端的字号仍用各自设置。
- 这是本机持久化的聊天偏好，不是按会话分别设置。勾选「应用设置」导出备份时会包含该比例；旧备份缺少这一设置时，不覆盖当前值。

## 聊天气泡

在「设置 → 外观主题 → 聊天气泡」分别打开「用户气泡」和「AI 气泡」，可以先看效果预览，再选择样式；选择后立即应用并保存。两侧独立设置，改一侧不会带着另一侧一起变。

- **用户气泡**：右侧的用户消息有 8 套预设：经典白描边、柔和投影、极简纯白、暗夜黑、漫画方格、清新绿、心动时刻、原版。默认「原版」，保留原来的用户消息外观。
- **AI 气泡**：默认「文档流」，正文直接显示在聊天背景上；也可选择与用户侧相同的 8 套气泡预设。因此 AI 侧共有「文档流 + 8 套气泡」可选，不要求与用户侧配对。
- 样式只改变消息正文的外观。AI 的 Markdown、代码块、表格、长文分段显示与已有聊天字号缩放继续保留；工具胶囊、思考、菜单和按钮不因此变成正文气泡。

这是本机的聊天偏好，不按会话分别设置，重启后保留。勾选「应用设置」导出备份时会包含两侧的选择；旧备份缺少某一侧或该项为空时，不覆盖这一侧的本机设置。只恢复聊天历史不会修改气泡样式，背景图片本体与路径仍不随这些设置导出。

## 语言

可以跟随系统语言，也可以直接指定一种已支持的语言。

## 终端外观

终端的配色主题、字体、字号、光标样式是单独一套设置，见[终端](/guide/terminal#外观设置)。
