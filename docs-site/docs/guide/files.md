# 文件浏览与代码编辑

::: tip 版本说明
文件树与代码编辑页从 1.11.0 起提供。
:::

侧边栏顶部的「文件」标签页用来浏览当前工作区与当前容器的文件，点文件默认打开全屏的代码编辑页（图片、音视频与安装包除外，见下文「图片、音视频与安装包」）。本地工作区和远程 SSH 工作区都支持，读写方式按当前模式自动决定。

## 浏览文件

「文件」页是一棵就地展开的缩进文件树，默认有**两个根**，还可以添加已授权的本机目录：

- **`workspace`**：当前工作区，默认展开。
- **当前容器**：名称就是当前选中的容器（如「内置 Alpine」），图标与设置里的「容器与镜像」列表一致。展开后是容器的整个文件系统（`/etc`、`/root`、`/usr` 等），默认折叠。本地 PRoot 容器里看到的是容器内的文件，远程 SSH 下看到的是远程服务器上的文件。

各根可分别折叠展开，右上角有刷新和「添加本机目录」入口。

- 点目录在原地展开或折叠，点文件直接打开编辑页（图片、音视频、安装包见下文「图片、音视频与安装包」）——无需逐级进入与返回。
- 目录排在文件前面，同类按名称排序。
- 文件按类型显示不同图标（代码、脚本、配置、文档、图片、音视频、压缩包等），采用与 App 全局一致的单色线性图标并跟随主题色着色。
- 着色规则类似 VS Code：`.` 开头的隐藏文件显示为浅色弱化，被工作区根 `.gitignore` 命中的条目显示为橙色（只看工作区根目录的 `.gitignore`，不解析子目录里的；容器里的文件不受影响）。
- 路径很深或文件名很长时不受影响：整棵树共享一个横向滚动，名称不会截断成省略号，左右滑动即可看全。
- 你展开或折叠过的目录会**按工作区记住**，关掉 App 再打开、或者切走再切回同一个工作区，都会恢复上次的展开状态。
- 容器根只在展开时才去读目录；读不到（容器未安装、远程未连接）时该行会标红，不影响工作区那棵。

AI 文件工具支持通过符号链接读取和写入文件，本地模式的绝对目标按容器路径映射，远程模式则按服务器文件系统解析。读取或写入会访问链接目标，删除、重命名或移动链接本身则保留目标内容，包括目标已不存在的链接；循环链接会报错，路径中的 `..` 按实际链接目标逐段解析，不先将它当成普通字符串合并。

复制或移动会在覆盖目标之前检查源和目标是否实际重叠，不能通过路径别名或符号链接把目录写入自身或其后代，也不能用源的祖先目录作覆盖目标。复制顶层链接会复制其目标内容，目录内的子链接保留链接本体；移动链接只移动链接本体。遇到拒绝时请检查目标路径，不通过换一种路径写法绕过。

AI 局部修改文件时兼容 Linux 常用的 LF 与 Windows 常用的 CRLF 换行，不需要先转换整份文件。替换内容沿用目标区域的换行格式（目标区域没有换行时采用文件的换行格式），未修改的区域保持原样。缩进和其他字符仍需准确匹配；如果 AI 提示找不到原文，让它重新读取对应片段后再修改。

## 添加本机目录

在「文件」页点「添加本机目录」，从系统选择器选择手机或存储卡上的目录并授权。目录作为独立根出现在文件树中，不会复制进工作区，也不会切换当前会话；连接 SSH 时，本机目录仍与远端目录分开显示。

目前只支持系统外部存储选择器中能解析为真实路径、且 App 实际可读写的设备目录。云盘、自定义文档来源、持久授权失败，或系统限制访问的目录不会被当作可用根；系统显示「已授权」也不代表 App 一定能直接访问它。失败时请重新选择可访问目录，不需要也不会自动调用 Root。

长按本机根可选择「解除关联」，确认后只移除本应用中的入口，不删除原目录或文件。系统授权可能还被其他工作区共用，因此不会随解除关联一起撤销；需要完全撤权时请在系统设置中处理。撤权、存储卡拔出或目录来源改变后，该根会标记不可用；重新授权后，旧路径和旧操作确认不会自动转到新来源。

本机目录的链接不能越出所选授权目录；图片、预览与文件工具也遵守同一授权边界。文件页使用的本机路径不是远端服务器路径，不要直接作为 SSH 终端里的路径执行。

## 从手机上传

长按目标目录，选择「上传文件」可多选普通文件，选择「上传文件夹」可导入设备目录；上传目标可以是当前工作区、容器内目录或本机授权目录。文件选择支持系统文档来源，目录上传则受上述真实设备路径限制。

一次最多选择 128 个文件，文件名须各不相同；目录最多 10,000 项、64 层。内容分块传输，不要求把整个文件放进内存。传输期间可点取消；已经完成的文件不会因同批其他文件失败而回滚，请按结果检查目标列表，不把批量上传当成整批事务。

遇到同名普通文件会逐项询问覆盖；确认绑定当时的源、目标和内容，确认前文件或执行环境改变会拒绝旧操作。上传目录或跨后端复制遇到同名目录时，**不删除原目录、不自动合并**，请换名称或目标目录。若目标后端不支持安全的文件替换，覆盖会失败并保留原目标。

从选择器返回前若切换了工作区、容器、连接或目录授权，本次选择会失效，请重新发起；不会改用返回时的新环境继续上传。

## 从系统文件选择器访问

在支持系统文件选择器的应用中选择 AiCode，可以访问 `projects`（本地项目）和 `aicode`（AI 配置）两个目录。AiCode 顶层只用于展示入口，不能在此新建或删除；进入子目录后可按授权读写文件。指向共享范围外的符号链接不会展示，也不能通过它访问其它内部文件。

## 图片、音视频与安装包

文件树里的**图片**（png / jpg / jpeg / gif / webp / bmp）点击后进入应用内的全屏查看器，可以捏合缩放、双击放大，与聊天区看图一致。

**音视频**点击后进入[内置播放器](/guide/player)，支持常见文件、HLS 与 DASH 播放列表。远程 SSH 文件需要先下载临时副本，较大的文件首次打开会有等待；具体格式能否解码取决于手机与系统 WebView。切换工作区、容器或远程连接后，原播放会话失效，请从新环境重新打开。

**APK / APKS / XAPK** 点击后直接调起系统安装器（首次会引导你开启「允许安装未知应用」）。其余文件仍照常打开编辑页。

## 从对话中打开文件

AI 在对话中引用代码时会把路径写成可点击的链接（带下划线的 `文件路径:行号`）。不带行号的本地文件链接会进入[聊天内文件预览](/guide/file-preview)，可以只读查看常见文档并从菜单选择编辑；带行号的代码链接仍直接打开编辑页，并自动滚动到那一行，并使其**尽量停在屏幕中间**（目标行靠近文件开头或末尾时受滚动范围所限会贴边）。打开后你一滑动，自动定位就交还给你，不会再把画面拽回目标行。

支持工作区内的文件、AI 配置目录（`~/.aicode/...`）以及容器系统文件（`/etc/...`、`/root/...`），远程 SSH 工作区下同样可以打开。指向普通网址的链接不受影响，仍然用系统浏览器打开。

点到不存在的路径、目录，或超过大小上限的文件时，编辑页会给出对应的失败提示。

## 列表刷新

侧边栏的「文件」页可见时，本地工作区文件变动会**自动刷新**，不限于 AI 改的——你在终端里执行命令、或用其他 App 改动同样会被感知。

它监听的是工作区根、容器根（展开时）和当前所有**已展开**的目录，不递归整棵树；折叠某个目录后就不再监听它。收起侧边栏、切到「会话」页或进入设置、全屏终端后，文件树会保留最后画面并释放展示订阅，底层监听最多经过 5 秒宽限后停止。后台命令、文件操作和同步不因此暂停。

展开目录时只读取该目录，折叠时直接重排已有列表，不为折叠重新访问文件系统。收到目录变动或完成新建、改名、删除、粘贴后，只更新受影响的目录，不再每次重读整棵展开的树。连续变动会合并刷新；工作区根的忽略规则随根目录一起更新。

每次重新显示「文件」页都会重读当前展开的目录，包括从「会话」页切回来，以及宽屏下从其它页面回到聊天页；工作区根那行右侧的刷新按钮仍可随时手动重读。折叠的根不会为了刷新读取内容，重新展开时再读取。

远程 SSH 工作区无法监听远程文件系统的变动，外部修改主要依靠重新显示和手动刷新；通过文件页执行的写操作会主动更新受影响的目录。远程模式下读目录要走网络，可能有短暂的加载状态。相同工作区读取报错时，已显示的列表会保留并标记出错；首次读取失败则显示错误提示，可点击刷新重试。切换工作区、容器或 SSH 连接后会清除原范围的列表，旧请求结果不会用于新环境。这不保证识别所有本地挂载或权限异常，若列表与实际不符，请检查目录是否仍可访问。

## 新建、重命名、删除

**长按目录行**（工作区根、容器根、可用本机根或任意子目录），从底部菜单里选「新建文件」或「新建文件夹」，新建的条目落在该目录下。如果长按的是折叠状态的目录，会先自动展开好让你看到结果。

名称只能是单个条目名：含 `/`、`\` 或是 `.`、`..` 时确认按钮不可点击——避免误创建到其他目录。同名条目已存在或目录不可写时会提示失败，不会覆盖原有文件。

**长按文件或子目录行**可以重命名和删除；根节点不提供复制、剪切、重命名或删除，本机根可单独解除关联：

- **重命名**：只在同一目录内改名，不做跨目录移动；已展开的目录及其子目录会随新路径保持展开。
- **删除**：文件直接删除；文件夹会连同里面全部内容递归删除，所以会先弹确认框。

::: danger 删除不可撤销
删除不进回收站，也不受检查点保护。确认前请考虑清楚，尤其是删除文件夹。
:::

## 复制、剪切与粘贴

长按文件或子目录选择「复制」或「剪切」，再长按目标目录选择「粘贴到此处」。目标已存在同名条目时，会先询问是否覆盖；覆盖会替换原有条目及其内容，不可撤销。

不能在原目录用粘贴覆盖源条目，也不能把文件夹复制或移动到自身及其子目录。此类操作会被拒绝，源文件保持不变。

也可以在本机授权目录和远端目录之间复制或剪切。跨后端剪切会先完整复制并核验目标，再删除源；开始删源前取消会保留源，删源开始后的取消或错误可能留下部分源条目，应用会明确提示「已复制，但源未完全移除」，请检查两端，不要直接重复覆盖。跨后端暂不传输顶层符号链接；目录中的子链接保留链接文本而不展开，能否创建及在目标环境访问取决于文件系统权限。

剪切成功后，原目录的展开位置会跟随目标路径。剪贴板和覆盖确认仅用于复制或剪切时的工作区、容器、连接与本机授权；切换这些环境后会失效，需要重新选择源条目。收起文件页不会暂停已发起的文件操作，重新显示时会读取最新结果；切换执行环境则不会让旧操作继续写入新环境。

## 代码编辑页

点文件后侧边栏收起，进入全屏编辑页。

顶部左上是返回，右上依次是撤销、重做、保存、设置。撤销和重做在没有可操作内容时置灰，保存按钮只在有未保存改动时可点。

- **撤销按输入停顿分步**：连续快速输入算一步，停顿约半秒后再输入即算新的一步。一路撤销回打开时的样子后，文件名前的星号消失、保存按钮置灰，此时退出也不会再提示是否保存。
- 打开 Markdown 文件时，撤销按钮左边会多一个**预览切换**按钮，点击切到渲染效果，再点切回源码。预览和源码共用同一编辑状态，切换不会丢失未保存的修改。
- 预览是完整的 Markdown 渲染：**文档里内嵌的 HTML（居中标题、图片、表格排版、徽章等）会照常显示**，代码块带语法高亮，配色跟随应用深浅主题。文档里的相对路径图片（如 `docs/a.png`）会从当前工作区读取，远程工作区也能显示；网络图片（徽章、在线图表等）需要联网才能加载。预览页内点击链接不会跳转，避免离开当前文档。
- 预览不含 LaTeX 公式渲染，含公式的文档切回源码查看。
- 导航栏下面有一条文件名小栏：左边是文件名（有未保存改动时前面加星号），右边是光标的行列位置和文件编码。
- **底部快捷符号栏**可横向滚动，最左是光标左右移动和缩进（Tab），后面是编程常用符号（括号、引号、运算符、`;` `:` `|` `&` 等），点击即在光标处插入。软键盘弹出时符号栏会浮在键盘上方。
- 有未保存改动时，点返回或按系统返回键会先弹确认框，可以选「不保存」或「保存并退出」。
- **滚到文件末尾还能再上滑半屏**：最后几行不会紧贴屏幕底边，方便在文件结尾处编辑。

### 语法高亮

内置了这些语言：Kotlin、Java、Python、JavaScript/JSX、TypeScript/TSX、JSON/JSONC、YAML、Shell、Go、Rust、C/C++、CSS、XML、HTML、Markdown、PHP、Lua。`.kts` 按 Kotlin 高亮。未识别的类型按纯文本显示，不影响编辑。

配色用的是 VS Code 默认主题（深色 Dark+ / 浅色 Light+），随应用主题自动切换，编辑过程中切主题不会丢失未保存的内容。

### 编辑器设置

点右上角设置按钮进入独立的设置页，改动即时生效并记住，下次打开沿用：

- **字体大小**：滑块调节。
- **自动换行**：开启后长行折行显示，不再横向滚动。
- **显示缩进参考线**：默认开启。
- **显示自动换行箭头**：自动换行开启时在折行处画指示箭头，默认关闭。
- **显示空白符号**：把空格、Tab、换行可视化，默认关闭。

### 保存与并发

保存是**整份覆盖写回**，成功后提示「已保存」。

::: warning 不做外部并发检测
AI 工具或终端可能同时在改同一个文件，而保存会直接用编辑器里的内容覆盖，不会提示文件已被外部改动。如果你和 AI 可能同时动同一个文件，先让一方改完再动手，避免互相覆盖。
:::

### 限制

- **文件大小上限 2 MB**。超过上限的文件不打开——内容需要整份读进内存，再大会明显卡顿甚至崩溃。
- **不支持二进制文件**。打开时会嗅探文件开头，识别为二进制（图片、可执行文件、压缩包等）会直接提示，不会把乱码当文本载入。

## 工作区文件在手机上的位置

「文件」页浏览的是工作区内容，而工作区文件、AI 配置都存放在应用私有目录里，普通文件管理器默认看不到。想用外部工具打开或备份时，有几种办法：

**文件管理器挂载（推荐）**：App 实现了标准的 DocumentsProvider，可使用手机自带的「文件」管理器或第三方文件管理器（MT 管理器、Solid Explorer 等）找到并挂载 App 的私有根目录。挂载后能看到：

- `projects/`：工作区项目。通过「添加外部工作区」加进来的外部工作区不在这里，它们在你自行选择的设备目录下。
- `aicode/`：对应容器内的 `~/.aicode`，里面有 `skills/`（技能）、`docs/`（文档）、`mcp.json`（MCP 配置）等。

以 MT 管理器为例的挂载步骤：打开 MT 管理器 → 点左上角菜单（三横线）→ 侧边栏右上角的三个点 → 「添加本地存储」→ 系统文件选择器打开后点左上角三个点、选「AiCode」→ 点底部「使用此文件夹」。

**内置终端**：切到终端页，`cd ~/.aicode` 直接查看，用 `vi` 或 `cat` 查看编辑。

**交由 AI 处理**：AI 运行在容器里，你可以说“把 `~/.aicode/mcp.json` 打印出来查看”或“在 `~/.aicode/skills/` 下写一个新技能”。

**Root 设备**：直接进 `/data/data/com.aicode/files/`（部分系统等价路径是 `/data/user/0/com.aicode/files/`）。其中 `projects/` 是工作区根，`aicode/` 对应 `~/.aicode`，`rootfs/` 是容器系统。注意 debug 构建的包名是 `com.aicode.debug`，两者私有目录完全隔离。
