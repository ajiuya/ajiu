# 记忆与项目规则

本章介绍自动记忆与项目规则两项能力，用于保持 AI 跨会话的上下文连续性与项目一致性。

## 自动记忆

自动记忆是 AI 自行维护的长期知识库。对话中形成的项目约定、用户偏好与架构决策，AI 会自动记录并在后续会话中复用。

### 作用域

| 作用域 | 说明 | 存储位置 |
| --- | --- | --- |
| 全局 | 跨项目通用的个人偏好 | `~/.aicode/memory/` |
| 项目 | 当前项目专属的约定与经验 | 本地模式：`<项目根>/.aicode/memory/`；远程 SSH 模式：`~/.aicode/memory/projects/<项目名>-<标识哈希>/` |

项目记忆在远程模式下存储于手机本地，并按「项目名 + 服务器标识」隔离，不受容器重置影响。

### 记忆文件

每条记忆是一个 Markdown 文件，由 YAML frontmatter（`name`、`description`）与正文组成：

```markdown
---
name: conventions
description: 项目代码规范与命名约定
---
（正文）
```

### 生效方式

会话开始时，系统将全部记忆的摘要（名称与描述）注入提示词；需要详情时，AI 通过 `memory` 工具读取完整内容。

平台权限与安全边界始终适用。在这些边界内，本轮明确要求优先于长期偏好与默认约定；未明确指定时，按「用户记忆 > 项目规则 > 内置默认」处理冲突。

### 在设置中管理

打开「设置 → 记忆管理」，可分别查看**当前项目**和**全局**记忆。列表显示名称、摘要与正文预览；即使两个作用域有同名记忆，也分别列出，不因 AI 使用时的覆盖规则隐藏全局条目。

- **查看**：点条目阅读完整正文，可选中复制；返回列表不会修改内容。
- **新增**：点右上角「＋」，选择全局或当前项目，填写名称、一句话摘要及正文后保存。同一作用域已有同名条目会提示冲突，不默默覆盖；没有可用工作区时不能新增项目记忆。保存期间表单保持打开，若失败会保留草稿与错误提示，可修改后重试。
- **删除**：左滑条目，或在详情点删除，阅读确认后删除指定作用域的记忆。删除不可恢复；若确认期间内容已被 AI 或外部编辑器改动，会提示先刷新，不删除已变化的版本。
- **切换环境**：管理页打开后绑定当时的项目与执行环境。若切换工作区或服务器，页面提示重新加载；旧的新建表单或删除确认不能写到新项目。

SSH 模式下，原记忆管理操作仍使用上表说明的手机本地记忆，不把服务器文件当作手机记忆，也不会自动搬迁旧内容；与原来的 `memory` 工具读取同一份记录。

## 项目进展与交接

「设置 → 记忆管理 → 项目进展与交接」提供独立的项目历史，不改变原 Markdown 记忆文件。

- **登记与绑定**：登记当前工作区项目，选择把当前会话或工作区默认关联到哪个项目；查看记录不会自动绑定。明确解除绑定后，不会擅自改选另一个项目。
- **自动采集**：登记项目后可控制自动采集。记录限于工具开始／完成、项目内文件路径、有限结果状态和历史任务快照，不保存完整命令、终端输出或私有思考。工具报告成功也不等于构建、测试或整个项目已经完成。
- **最新交接**：选中项目后，顶部单独显示最新有效的手工交接。归档后仍可作为交接参考；撤销后会改为上一条有效交接，没有可用交接时显示空状态。点击可查看完整正文。
- **查看活动**：近期与归档历史分别查看，可按「全部／自动进展／手工交接」筛选并加载更多。筛选覆盖该项目的历史，不仅限于已经显示的一页；全部记录中也保留其他手工条目。自动进展的固定摘要随界面语言显示，手写摘要保持原文。
- **项目设置与容量**：项目开关、绑定和容量信息集中在可展开区域；收起后仍会提示容量不足或容量未知。容量按所有环境合计，归档不等于释放正文占用空间。
- **查看与交接**：点击「登记手工交接摘要」填写摘要与正文，也可从详情复制全文。撤销或归档需要确认；记录有版本冲突时不会默默覆盖用户修改。
- **跨会话继续**：在同一执行环境中发送「继续 X 项目」等请求，可召回该项目的交接与未解决事项。重名或多个候选项目时需要澄清，不会自动切换工作区或服务器。
- **中断检查点**：新进程发现旧检查点后，把其转为中断、结果未知、待核验的历史。它只补充工作背景，不恢复原协程、不自动重放工具，也不把历史 Todo 当作当前任务列表。

项目身份区分本地容器配置及 SSH 主机、端口、账号与项目路径；切换环境后旧页提示刷新，旧表单不能写到新目标。历史作为待核实材料送给模型，不是新指令、计划批准或工具授权。容量不足、记录被撤销或部分内容省略时，会如实标明，不能据缺失内容猜测任务已完成。

### memory 工具

| 参数 | 说明 |
| --- | --- |
| `action` | `read` / `save` / `edit` / `delete` / `list` |
| `name` | 记忆名称（即文件名） |
| `description` | 摘要，`save` 时必填 |
| `content` | 正文（Markdown），`save` 时必填 |
| `edits` | 局部编辑列表，语义与编辑文件一致 |
| `scope` | `project`（默认）或 `global` |

同名记忆项目级优先于全局。更新既有记忆时建议使用 `edit` 局部编辑；涉及踩坑经验的内容，应在验证根因后记录。

## 项目规则

项目规则有两处来源：全局目录 `~/.aicode` 与当前工作区根目录。两处各自优先读取 `AGENTS.md`，不存在时回退 `CLAUDE.md`。全局规则用于跨项目通用的约定，工作区规则用于项目专属的规则、架构约束与构建指南；两处冲突时以更具体的工作区规则为准，并遵循上述权限边界与冲突处理顺序。

### 生效方式

两处规则在会话开始时自动加载并一并注入提示词，无需手动配置；每份文件内容超过 32,000 字符时将被截断。

### 自定义加载约定

项目规则的加载约定对应提示词片段 `15-project-rules.md`，可通过 `~/.aicode/prompts.custom/15-project-rules.md` 覆盖，见[自定义提示词](/guide/custom-prompts)。
