# 功能总览

本页作为阿九工作台（Ajiu Workbench）使用手册的快速导览索引，整理了主界面核心工作流与设置页各功能入口对应的文档。如需直接观看操作演示，可先浏览[视频教程](/guide/video-tutorials)。

::: tip 版本说明
标了版本的条目（如「1.11.0 起」）表示该功能自该版本起引入。
:::

## 核心工作流与主界面

| 功能 | 说明 |
| --- | --- |
| 聊天交互与工作区 | 居中的会话标题与「模型名（供应商名）」、右上竖三点里的新建会话/Git/终端入口，以及侧边栏、消息队列、任务待办与工作区切换 → [文档](/guide/chat) |
| 生成速度 | 思考程度旁的 tok/s：每 250 毫秒采样正文与思考的估算，结束后按上游真实输出用量校准单次调用平均速度，缺用量时保留估算 → [文档](/guide/chat#生成速度) |
| 回复用量与上下文占用 | 每轮最终回复的圆环在复制后、更多前；点击查看总量、有效输入预算及五项本地估算，旧缺分项显示未记录；可手动压缩当前会话完整上下文，不改历史快照 → [文档](/guide/chat#上下文占用) |
| 工具过程与摘要 | 当前轮新工具默认展开，原始正文开始到达时统一折叠；摘要显示实际调用次数、耗时、失败数，未结束不当失败，可再手动展开 → [文档](/guide/chat#回复与工具卡片) |
| 计划审批 | 复杂、高风险或明确要求先规划时，先只读检查，再审阅完整方案；批准后执行，拒绝则结束本轮，不是模式切换 → [文档](/guide/permissions#计划审批) |
| 会话目标（Goal） | `/goal` 设定目标，AI 自主循环推进；等待计划审批时停下，拒绝则暂停目标（目标功能自 1.13.0 起）→ [文档](/guide/goal) |
| 检查点与撤销 | AI 修改前自动快照，支持一键安全回滚 → [文档](/guide/checkpoint) |
| 终端交互 | 多标签会话、辅助按键栏、配色与字体设置 → [文档](/guide/terminal) |
| 内置浏览器 | WebView 浏览器，支持 AI 自动化操作网页（导航、点击、填表、截图等）（1.12.0 起）→ [文档](/guide/browser) |
| 内置播放器 | 工作区／SSH／公网媒体、HLS／DASH、选集、倍速、进度记忆、全屏、画中画、可选后台控制与在线目录搜索 → [文档](/guide/player) |
| 聊天内文件预览 | 应用内查看 Markdown、HTML、PDF、文本代码、JSON、表格及压缩包条目，关闭后保留聊天位置 → [文档](/guide/file-preview) |
| 文件浏览与代码编辑 | 缩进树形目录、语法高亮、内置代码编辑器（1.11.0 起），以及工作区文件在手机上的位置与访问 → [文档](/guide/files) |
| Git 版本管理 | 可视化状态管理、分支切换、提交历史、回退与删除（1.11.0 起）→ [文档](/guide/git) |
| 平板与大屏适配 | 响应式分栏、常驻侧边栏、并排双栏工作台（1.11.0 起）→ [文档](/guide/tablet) |

## 设置项与扩展能力速查

### 通用设置

| 入口 | 说明 |
| --- | --- |
| 偏好设置 | 全局偏好：无效模型清理、启动时会话、回车发送、首字与间隔超时、重试次数、自动压缩阈值、sendFile 单文件上限，以及正文/思考的打字机调速面板（30–350 字符/秒、默认 30；不是 tok/s）→ [文档](/guide/general) |
| 外观主题 | 二级页面保留明暗模式、配色与莫奈取色，集中设置原有全局水印和独立的聊天背景；聊天背景使用真实 0%–100% 不透明度 → [文档](/guide/appearance) |
| 聊天字号 | 80%–140%、默认 100%，带预览；正文、用户消息、思考与 Markdown 代码同步缩放，菜单按钮不变 → [文档](/guide/appearance#聊天字号) |
| 语言 | 跟随系统或单独指定支持的语言 → [文档](/guide/appearance#语言) |
| 终端设置 | 终端配色、字体大小与光标样式 → [文档](/guide/terminal) |

| 插件 | 从本地 ZIP 预览、安装并确认信任；了解手机本地进程、依赖准备与工作区操作各自的权限边界 → [文档](/guide/plugins) |

| Root 工具 | 须手机已有 root、真实 su 授权且本机总开关开启；宿主只读可确认时默认放行，修改或不确定操作可仅本次或本聊天同来源及身份全部后续修改与不确定操作，包括不同命令／目标；关闭撤 pending／permit 及相关 grant，不回滚写入，输出仍交给已选 AI 服务商 → [文档](/guide/permissions#root-工具) |
| 自定义提示词 | 数字片段逐条启停、项目状态优先、停用不删内容且不回退同号；下一模型请求生效，不改变平台/工具硬权限 → [文档](/guide/custom-prompts) |
| 记忆与项目规则 | 跨会话长期记忆，以及 AGENTS.md / CLAUDE.md 项目规则 → [文档](/guide/memory) |

### 权限与后台

| 入口 | 说明 |
| --- | --- |
| 工具授权 | CHROOT 正常容器操作默认放行，仅可识别的 Android 宿主系统／共享内核路径修改或具体宿主路径线索下行为不明确时审批；Root／Shizuku 直接操作宿主，可确认只读默认放行，修改或未知先审批。ONCE 或本聊天同工具、同来源及身份全部后续宿主修改／不确定操作，含不同命令／目标。新宽 grant 仅内存、重启清除，来源／身份／Root 代际／配置选择／实例变化需重审；PRoot／SSH 精确命令旧策略、显式禁止与独立确认保留，非沙箱 → [文档](/guide/permissions) |
| 软件权限 | 安装未知应用、存储、电池优化、自启动、Shizuku 系统权限、本机 Root 总开关，以及手机构建开关与 Gradle 参数面板 → [文档](/guide/app-permissions) |
| 后台运行 | 后台保活、屏幕常亮、AI 完成与实时通知；计划审批通知只提示回 App 审阅 → [文档](/guide/background-run) |
