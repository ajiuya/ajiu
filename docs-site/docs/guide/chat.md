# 聊天界面导览

本页说明主界面上各按钮与区域的作用。

新建空白对话时，欢迎语显示在页面中央偏上的位置。点击底部输入框唤起键盘后，欢迎语会随输入框上移，尽量保持在顶部标题栏与输入框之间；收起键盘后回到原位。

## 顶部标题栏

- **菜单按钮**（左上）：打开侧边栏，管理会话列表和浏览文件。
- **会话标题与模型名**：上面一行是当前会话名，下面一行显示「模型名（供应商名）」，两行都以屏幕水平中心对齐。长名称会省略显示。
- **更多操作**（右上角竖向三点）：点击展开二级菜单，原有三个入口移到这里，行为不变：
  - **新建会话**：新建一个对话。当前工作区如果还留着一个没发过消息的空会话，会直接切过去复用，不会再新建一个。
  - **Git 入口**：跳转到 Git 版本管理页。
  - **终端入口**：跳转到终端页。

远程 SSH 模式下，标题栏下方会多一行：左侧是 SSH 连接状态（圆点加文字），右侧是当前会话的 token 累计（上箭头输入、下箭头输出）。本地模式不显示这一行。

## 侧边栏

点击左上角菜单按钮，或从屏幕左缘向右滑动。顶部有「会话」和「文件」两个标签页。

### 会话页

会话按最后回复时间从新到旧排列，并按时间分组（今天 / 昨天 / 7 天内 / 30 天内 / 更早按月份）。置顶的会话单独放在最前面的「置顶」分组，卡片是浅蓝色背景。浏览列表时，收到新回复后仍可从正在查看的会话附近继续浏览。

短按切换会话，**长按弹出操作菜单**：

- **置顶 / 取消置顶**：置顶后固定排在最前。
- **重命名**：改会话标题，不影响排序。
- **导出**：导出这个会话。
- **批量选择**：进入多选模式，支持勾选多个会话、一键「全选」以及「批量删除」（带二次确认）。按左上角 × 或返回键退出多选模式。
- **删除**：会弹确认框，确认后删除该会话及其所有消息。

派生过子代理的会话，行尾会显示子代理数量和展开箭头，点击展开后可在下方查看其子代理（**1.11.0 起**），详见[子代理](/guide/subagent)。

侧边栏 Tab 栏下方是**搜索聊天记录**（**1.12.0 起**）：输入关键词即可跨当前工作区的所有会话搜索消息内容，列表区就地显示命中结果（会话标题加命中片段，关键词高亮）。点击一条结果会切换到对应会话并定位到该消息；点击搜索框右侧的 × 或删空内容即回到会话列表。搜索只覆盖当前工作区，且只匹配你和 AI 的正文，不含工具执行输出。

### 文件页

浏览当前工作区的文件，点击文件打开代码编辑页（**1.11.0 起**），详见[文件浏览与代码编辑](/guide/files)。

侧边栏底部有「播放器」、「浏览器」（**1.12.0 起**）和「设置」入口。播放器可打开音视频、管理播放列表和查询在线目录，详见[内置播放器](/guide/player)。

## 请求速度

打开聊天页右上角三点菜单，在「请求速度」二级选项中选择**标准、快速或极速**。默认标准，选择作为本机全局偏好保存；菜单同时显示当前模型实际适用的档位，切换协议或模型不会抹掉你的偏好。

- 这项设置只请求服务商的 API 优先级，不改变思考强度、工具权限或模型本身。
- 新选择从下一份新请求生效；已经构建的请求及其网络重试沿用原档位。
- 不适用的模型或协议使用标准或快速回退。菜单中的适用判断不等于账号已经有对应权益；实际支持、排队效果和收费以服务商为准。
- 快速或极速可能产生额外费用。服务商拒绝该档位时会报告错误，不会偷偷切换账号、另换付费通道或改回标准重复请求。

三点主菜单与「请求速度」二级菜单使用同一圆角弹层，各项保持统一间距；没有插件内容或错误时，不保留空插件区域。「项目工具」打开独立的圆角浮层，具体用法见[插件项目工具](/guide/plugins#页面动作与工作区工具)。同一三点菜单提供「MCP 服务器」快捷入口，复用[设置中的原管理页面](/guide/mcp)，不创建第二套服务器配置。

## 输入框下方工具栏

从左到右：

- **模型按钮**：显示当前模型，点击弹出选择弹窗。顶部有搜索框可以模糊筛选，模型按供应商分组，点击分组标题可以折叠或展开（折叠状态会被记住，重开弹窗或重启后保持；搜索时自动展开命中的分组），每行标注能力标签（`Image`、`Tools`、输入输出长度），点击后保存到当前会话；执行中切换的生效时机见下文。
- **工作区按钮**：显示当前工作区名，点击弹出工作区管理面板（见下）。
- **文件按钮**：上传文件作为附件，AI 可以读它的内容。
- **图片按钮**：上传图片作为附件。点击直接打开系统相册，可以多选。需要当前模型支持图片输入。发给模型的是缩小后的副本（长边最多 1568 像素），工作区里保存的仍是原图，请求体积和流量因此小很多。相机拍的大图也可以直接上传（原图上限 40 MB）。
- **发送按钮**：AI 空闲时是普通发送；AI 正在工作或等待计划审批时，输入框为空则显示停止按钮，有内容则显示橙色发送按钮（消息会排队）。

**执行中切换模型**：不必停止任务，同一任务的下一次主模型请求准备时会读取最后已保存的选择。

- 正在生成的回复、当前请求的网络重试和已经启动的工具批次仍按原来的请求完成，不会被切模型打断或重跑。
- 若请求准备（包含必要的上下文压缩）已经开始，此时的选择顺延至下一次请求；任务已经结束时不会为切换模型额外发起请求。
- 界面显示的是会话所选模型，不表示正在传输的请求已换用它。切换目标固定为点击时的会话及同一工作区内已有的直属子代理，它们分别在自己的下一次请求准备时生效；即使子代理原来单独选过模型，这次也会同步。不会递归影响孙级子代理、兄弟或其他根会话，随后切换聊天也不会改错目标。在子代理会话内操作时不会反向修改其父会话。后续新建子代理仍按派发时的模型选择规则处理。
- 新请求按新模型的窗口和图片能力处理上下文。窗口不足且无法压缩时会提示错误，不会沿用旧模型继续；切换不会重置自动续写预算、审批或权限。执行中的切换也不会修改全局默认模型。

普通工具调用默认自动放行，不需要切换 Agent 工作模式；复杂、高风险或你明确要求先规划的任务，先走下文的[计划审批](#计划审批)，普通小改不强制。普通 Root、Shizuku 调用，以及容器/SSH 中显式 `sudo`/`su` 与适用高危命令的审批可选择「拒绝」「仅本次允许」「本会话始终允许」。授权只适用于当前聊天会话且身份范围仍有效的记录，不跨会话或继承给子代理；独立 Root 关闭再开启、Shizuku 断开、重启或切换身份后须重新授权。独立 Root 需手机已有 root、系统 su 管理器授权并开启默认关闭的本机总开关；Root 启动的 Shizuku 由你在 Shizuku 应用中准备并授权本 App，两通道分别授权。**Root 与 Shizuku 的高危命令仍只可拒绝或仅本次允许**，已有普通会话授权不能豁免，禁止规则始终优先，详见 [工具授权](/guide/permissions)。本地容器和远程 SSH 是独立的执行环境选择，不等同宿主 Root。

文字输入区采用紧凑的单行高度，收紧文字区、工具栏与按钮外围的纵向留白，保留原字号、发送／停止按钮和用量环尺寸；随多行内容增长，到上限后在框内滚动，不用固定高度裁切文字。右上角续接气泡、附件和消息排队仍按原有方式操作。输入的内容长到超出输入框高度后，输入框右上角会出现**展开按钮**：点击即用整屏编辑这条草稿，右上角「收起」或系统返回键退出全屏。全屏里修改的内容实时同步回输入框，两边是同一份草稿，收起后按发送即可。

上传的附件会以预览卡显示在输入框上方，发送前可以移除。上传较大的文件需要一定时间，期间输入框上方会显示上传中的提示，传完自动变成预览卡。点击图片缩略图可以[全屏看大图](#全屏看图)。已发送或工具返回的音视频附件可点击进入[内置播放器](/guide/player)；AI 返回附件本身不会启动播放器。其他文件附件可打开[聊天内文件预览](/guide/file-preview)，支持 Markdown、HTML、PDF、文本代码、JSON、表格等；预览覆盖聊天而不销毁原列表，关闭后继续原阅读位置。

未发送的文字草稿按会话持久化保存到本地。

滚动消息列表时，输入框区域会淡出到 40% 透明度以减少干扰，停止滚动后恢复。

## 生成速度

输入区的思考程度旁显示生成速度，`tok/s` 表示每秒生成的 token 数；没有可用样本时显示 `— tok/s`。

- **生成中**：收到首段正文、思考或工具调用开始后先积累约 1 秒观察样本；当前会话已有速度时先保留最后读数，尚无有效样本时显示 `— tok/s`。之后每 250 毫秒采样，按近约 3 秒接收窗口并平滑波动，显示为 `≈12.3 tok/s`。首包已经收到的内容作为窗口起点，不当成接下来一秒的新产量。供应商提供可识别的工具参数流（例如编写长文件）时也更新测速，即使参数预览已达到显示上限，计数仍继续；重复的累计参数不会重复计数。暂时没有新内容时保留最后有效读数，等新样本到达再更新。它是本地接收速度的估算，不是供应商内部逐 token 的精确生成速度，也不设固定最高速度。
- **本次模型调用结束**：最终显示本次成功请求的平均输出速度，即输出 token 数除以从实际发出请求到完整接收结束的耗时，包含等待首段内容的时间。此前失败的尝试、重试间隔、请求结束后的界面收尾，以及工具执行和授权等待均不计入这个耗时。上游返回真实输出 token 数时，最终值不带 `≈`；没有返回用量时，仍用已收到的正文、思考和工具参数估算，保留 `≈`。即使只收到最终整包，只要有真实用量和有效请求耗时，也能计算最终平均值；请求耗时未知、不足 250 毫秒，或没有可用 token 数时，保留上一读数，不人为补时间来生成新速度。最终读数在等待工具、任务结束、失败或手动停止后继续保留；失败或停止前尚未收到最终用量时，保留的是最后一次实时估算。
- **重试、换 Key 或开始新的模型调用**：统计样本重新计时，每次模型调用分别计算平均速度；显示先保留当前会话的最后读数，收到新的有效速度后再替换。切换会话时显示各自的读数，没有样本的会话仍显示 `— tok/s`。更换模型、回退历史或删除会话会清除对应旧读数；读数只在本次应用运行期间保留，重启后需重新采样。

不同供应商的用量统计与思考 token 口径可能不同，部分内容也不会以可见文本流式返回，因此这里不承诺每家供应商都有精确的实时 token 速度。生成中显示的是最近接收窗口的字符估算，结束后显示的是整个成功请求的平均值，二者数值可能不同。结束值使用客户端实测请求耗时，仍会受到网络传输、缓冲、尾部用量等待及客户端接收进度的影响；中转站可能采用服务端生成耗时等其他口径，因此不能保证与其调用日志完全相同，也不能据此精确比较模型内部生成性能。它也不同于[回复下方的本轮总耗时](#回复下方的用量与耗时)，后者仍包含工具执行和授权等待。

## AI 询问面板

AI 需要你选择方案时，会在聊天输入框上方显示询问面板。选择预设选项，或选择「其他」填写自己的回答，再点「确认」提交；也可以点「补充」，回到聊天输入框补充说明。

填写「其他」时，面板会随键盘弹出缩小可见区域。问题较多时，可以在面板内部上下滚动，找到输入框和底部操作按钮。面板标题可点击收起或展开。

## 计划审批

AI 先只读检查并提交实施方案后，聊天输入区上方会出现**计划摘要卡**，显示计划标题、所属会话和「等待计划审批」。点「查看计划」打开底部审阅面板，滚动查看完整方案；长计划可继续向下阅读，手机与平板均可使用。

审阅面板只有两种决定：

- **批准执行**：确认当前方案，AI 获批后才继续发起操作；不设「始终允许」。
- **拒绝并结束**：可先填可选的拒绝意见。本轮立即结束，有持续目标时一并暂停，不会自动再让 AI 修改重提，也不会因后台完成提醒或排队消息继续执行。要改方案，请在下一条消息中要求 AI 调整后重新提交。

收起审阅面板不代表批准或拒绝，可从摘要卡重新打开；点停止会取消等待。多个会话与子代理各自审批，处理前请核对卡片和面板上的会话标题。侧边栏会显示等待审批状态，后台通知会提示「等待计划审批」，点通知后需回到 App 阅读，不能直接在通知中批准。

与计划提交混在同一批的其他工具调用一律标记为**未执行**，批准后也不会补跑，AI 要在新一批重新发起。若计划没有取得有效批准，本轮结束且不会自动续跑。待审批请求只存在于当前进程内存，界面重建仍可接回同一请求；进程重启后需重新提交，历史卡片不是有效的待审批入口。

计划批准不扩大任务授权，也不绕过禁止规则、Shizuku、root 或高危操作审批。任务待办仍保留：计划审批用于决定方案是否执行，待办列表用于跟踪进度，两者互不替代。详见[计划审批与工具授权](/guide/permissions#计划审批)。

## 工作区管理

点击工作区按钮弹出的面板里可以：

- **切换工作区**：点击即切换。如果当前有正在运行的 AI 会话或终端标签，会先弹确认框——切换会停止它们。
- **新建内部工作区**（本地模式）：输入名称，在应用私有空间中创建一个独立文件夹。远程 SSH 模式下入口显示为「新建工作区」，文件夹创建在服务器上。
- **添加外部工作区**（本地模式）：把设备上已有的目录作为工作区。首次点击会显示风险确认弹窗（AI 会直接读写你的真实文件），可以勾选「不再提示」。只支持从「内部存储」或「SD 卡」选择文件夹，云盘之类的其它文件提供方不支持。
- **删除工作区**：内部工作区连同文件一起删除；通过「添加外部工作区」加进来的外部工作区只解除关联，**不会删除目录内容**。

工作区是 AI 操作项目的根目录，不等于宿主系统的安全沙箱。`Shizuku` 与 `Root` 直接作用于宿主 Android，批准前请核对实际命令目标和权限，不要把它们当作仅能操作工作区的工具。

## 斜杠命令

在输入框输入 `/` 会弹出命令菜单，**内置命令排在前面（按字母序），技能排在后面（也按字母序）**。命令较多时，可以在菜单内上下滑动查看；继续输入命令名可以筛选列表，点击条目即可补全到输入框。

内置命令：

- `/compress`：手动触发当前会话的上下文压缩。
- `/init`：让 AI 分析当前工作区代码库，生成或改进项目规则文件 `AGENTS.md`（项目根已有 `CLAUDE.md` 而无 `AGENTS.md` 时改进 `CLAUDE.md`）。可带参数指定关注点，例如 `/init 关注测试与发布流程`。
- `/usage`：查看今日与累计的调用次数、token 用量与预估费用（全局统计，跨会话）。
- `/goal`：设定/查看/暂停/恢复/清除当前会话的持续目标，AI 自主循环推进至达成或预算耗尽。详见[会话目标](/guide/goal)。

技能：

- 每个已启用的技能都能用 `/技能名` 直接触发，AI 会把该技能的正文作为本轮指令执行；菜单里技能右侧带「技能」标记。
- 技能可以带参数，例如 `/pdf-report a4`：参数会替换技能正文里的 `$ARGUMENTS` 占位符；正文没有占位符时，参数会追加到末尾。

命令在 AI 忙碌时会进队列，当前任务正常结束后自动执行；因计划未获批准而停止时，不会从队列自动继续。命令文本会作为用户消息显示在对话里，并进入上下文。

## @ 引用文件

在输入框输入 `@` 会弹出文件搜索菜单，输入关键词即可模糊匹配当前工作区的文件（按文件名与路径匹配，不区分大小写）。点击条目会把 `@相对路径` 插入输入框，作为给 AI 的引用——AI 收到后按需读取该文件。

- 文件列表由容器内的 ripgrep 生成，自动遵守 `.gitignore`，跳过 `.git`、`build` 等目录。
- 每次打开 `@` 菜单都会重新拉取一次列表（大工作区首次可能有短暂加载），关闭后即丢弃，保证拿到最新文件。
- 本地模式需先初始化容器；容器未就绪时菜单会提示无法搜索。
- 远程模式需要远端服务器已安装 `rg`。

## 上下文用量与压缩

发送按钮外圈反映模型可用输入预算的占用，而非累计消耗。发送前会估算新输入、回复和工具结果增加的用量，模型返回后再用实际报告校准；读屏说明会区分预计用量。切换模型、压缩和回退后，旧用量基线不再沿用，后续请求会重新计算。

也可以点击已结束回复下方的上下文圆环，在详情面板点「立即压缩」。无论从哪一条历史回复打开，按钮都只处理**当前会话现有的完整上下文**，不是只压缩点开的那一轮；已保存的历史占用和分项快照不改写。当前会话正在执行、等待工具或计划审批、或已经在压缩时，按钮会禁用，请等待空闲后再试。

上下文接近阈值时，较早的对话会转成接手摘要，最近消息继续保留。历史整理和摘要材料处理在后台进行，压缩期间仍可浏览消息。压缩成功后，分隔线和摘要卡片显示在本次压缩触发的位置，而不是被压缩历史的截断处。长历史会先分块整理，再按原先顺序归并成一份接手摘要；处理量较大或压缩模型窗口较小时，可能增加等待时间和调用费用。

原来的状态行会显示 **「正在压缩上下文 37%」**，三点动画保持不变。这个百分比表示已成功处理的历史材料，不是已等待时间、模型生成速度或上下文占用率：

- 等待模型回复或重试时，进度可能停留在原值，不会为了动画自动增长。
- 历史材料处理最高到 **90%**；长历史还在归并时可能暂时停在这里。
- 验证通过并进入保存时显示 **95%**；只有确认完成或确实无需替换历史后才到 **100%**，随后状态行收起。
- 进度按会话分别记录，切换会话不会显示另一会话的百分比。压缩期间可使用原来的停止按钮；取消不会把半截摘要替换进历史。若保存已经提交，停止也不会撤销已经完成的压缩。

单次压缩的总时限为 **35 分钟**，覆盖分块整理、归并和重试，不会每处理一块就重新计时；单次摘要工作仍有最多 32 次模型调用的限制。首内容等待、接收途中停滞、总时限和缺少完整结束标记会分别提示。压缩请求会向兼容服务发送摘要专用输出上限，不改变普通聊天的默认输出行为。

遇到总超时或后续分块失败时，原历史保持不变。在同一 App 进程内手动重试，若会话来源、模型、提示词与请求设置未变，可复用仍有效的完整分块，从失败处继续处理，不为复用块重新产生调用。检查点仅在内存有界保留，过期、被淘汰、取消、回退、切换模型或压缩成功后失效；退出进程后也不会恢复。它不是已经保存的摘要，不会自动续跑或重置调用预算，也无法找回旧版本失败时未保留的分块。

遇到部分暂时性错误、压缩服务上游连接中断或输出截断时会在限制内重试；每块普通失败最多尝试两次，仍受整次总时限和调用次数限制，不会把不同次尝试的半截输出拼成一份摘要。服务端仍无法确认摘要完成时，会单独提示上游连接中断并保留原历史；这不代表旧工具未执行，也不会自动重放工具。摘要为空、仍不完整、无法释放空间或处理失败时，保留原历史并提示原因。明确的聊天上下文超限仍最多自动压缩恢复一次，仍失败时请缩短输入、减少工具或检查模型窗口设置。

回退最近的对话时，回退点之前仍有效的压缩摘要会保留，不会把所有旧历史一起展开。只有跨过某次摘要时，才按保存的覆盖关系还原该摘要对应的较早消息；回退点以后的消息不会重新进入上下文。

模型窗口很小（例如本地部署的 30k 上下文）时，系统提示词和工具定义本身就会占掉大半窗口。如果这部分加上必须保留的最近消息已经超过触发线，压缩也腾不出空间，此时不会反复压缩。请在「设置 → AI 供应商」里确认该模型的上下文窗口填写正确，并尽量减少启用的工具、MCP 与记忆条目。

## 界面重建与进行中的任务

只要应用进程仍在，聊天界面被销毁后重新创建不会主动停止已经接受的任务。重新打开对应会话后，会接回当前正文、工具和等待审批状态，不会为接回画面重新发送同一请求。切换会话不改变已接受任务所属的会话或工作区，斜杠命令和压缩也按发起时的会话处理。

等待中的审批仍需你明确选择；界面重新打开不是批准。主动停止、删除会话、回退对话或切换执行环境仍按原规则停止或使旧任务失效，不会因为运行器常驻而绕过这些操作。

这不保证系统杀进程后继续运行，也不替代后台保护。系统真正结束进程后，仍按下文的确认恢复处理；启动或重回页面不会自动重放工具、队列或旧批准。任务被系统中断时，请先核对当前文件状态，再用聊天输入框的气泡续接。

## 中断后的确认恢复

请求被接受后，会保存待发顺序、运行阶段及有界的可见正文草稿。进程被结束、网络重试耗尽或模型中断后，打开有待续接请求的会话，输入框右上角会出现「继续｜放弃」。点击后才会处理待续接请求。

- 这颗气泡负责当前会话和它的直属子代理。多条待续接时，数字是当前显示的待确认请求总数。每次点击处理各空闲会话最早的一条。续接被接受并开始运行后，该会话的后续待确认项会暂时隐藏；没有其他待决定项时，气泡消失。未接受的后续请求仍保留，等会话空闲后再显示；交接失败或再次中断时也会重新出现。其他空闲直属会话的待确认项不受影响。想单独处理一个子代理，可以打开它自己的会话。
- 点「继续」会按原断点接续。有工具结果未知时，先核对提示中的工具和实际文件或系统状态，再在气泡上确认继续。项目、容器配置或 SSH 环境不一致时，请切回原环境再继续。
- 点「放弃」只移除当前可见批次仍在等待续接的请求，不会处理运行期间隐藏的后续项。已经启动的任务可以用各自的停止操作处理。

尚未开始的请求会处理原输入，正文从保存的断点接续，已有的工具结果用于后续处理。尚未执行的工具需要重新决定是否执行，有结果未知的旧调用需要先核验。计划审批、Root／Shizuku 单次许可和待决审批均按当前请求处理。保存的会话授权仍须按当前身份范围核验。

同一原请求的连续续接归在原来的聊天轮次中。中间有其他新请求时，聊天中会用「继续之前的任务」区分。已保存的断点草稿随续接记录展示，并标为「不完整、未验证」。

长草稿保留开头和断点附近的尾部，省略处会明确标出。草稿是节流保存而非每字同步，强杀前尚未落盘的内容仍可能丢失；已经产生的工具副作用需要在对应文件或系统中核实与处理。看到「结果未知」不表示工具一定没执行。删除会话、回退对话、清空或导入备份后，过期运行不能恢复写入。

模型达到输出上限时会在预算内自动续写；同一请求最多自动续写三次，续写前累计输出预算为 64k token，缺少真实用量时采用估算。达到限制后保存现有结果并提示，不伪装成功；显式恢复也不会通过重启重置这份预算。Goal 回合失败后会停止自主续轮，需你明确恢复目标。

恢复后，AI 会先读取当前待办状态，保留你后来修改的任务与完成标记；编辑或覆盖已有文件前，需要重新读取文件。若提示先重新读取，应读取当前文件后再按现状修改，不能把重启前的内容当作当前版本。

已保存但尚未交给模型的后台任务和子代理通知，会在重新打开后等待你确认；对应子任务的中断状态也会保留。通知不是执行许可，不会因重启直接启动 AI；确认放弃只处理对应待确认项。项目级跨会话交接见[项目进展与交接](/guide/memory#项目进展与交接)。

## 消息队列

AI 工作时输入框仍然可用。输入内容后点橙色发送按钮不会打断当前任务，而是加入**待发送队列**：

- 队列面板显示在输入框上方，列出排队消息的序号和摘要；点标题栏可收起/展开，弹窗或键盘弹出时会自动收起。
- 当前一轮任务正常结束后，队列里的下一条自动发送，多条按顺序执行。计划被拒绝或没有取得有效批准时，本轮不会消费队列自动续跑；请主动发送下一条消息说明如何继续。
- **拖拽排序**：按住每行左侧的拖拽手柄（☰）上下拖动，可调整排队消息的执行顺序。
- **编辑**：点每行的铅笔图标可修改普通排队消息的内容，确认后更新；从子代理协作卡片发送的补充指令不支持在队列中编辑。
- **立即插入**：点每行的闪电图标会把普通排队消息立即发给正在工作的 AI——不再等当前轮结束，而是直接注入 AI 正在进行的工具结果中，让它当轮就按新内容调整。若当前轮 AI 没有调用工具（正在纯文本输出），则会在本轮结束时作为下一条发出。从子代理协作卡片发送的补充指令不支持立即插入。
- 普通执行中点「停止」会跳过当前轮，立即执行队列里的下一条；等待计划审批时，点停止可取消该审批请求。
- 每条消息右侧的 × 可以把它从队列移除。

从子代理协作卡片发送的补充指令可在目标子会话的队列中拖拽排序或删除，但铅笔与闪电按钮不可用；要修改内容，请先删除旧条目，再重新发送，原来的发送记录不会被改写。删除这类排队指令，或停止全部任务时清空队列，会留下取消记录，不会把它算作已执行。

拒绝计划不会删除原队列或待处理的后台提醒，但它们不会自行唤醒该会话。你主动发送新消息或选择「立即插入」才表示继续处理；这不等于批准原计划，若要实施仍需调整后重新审阅。持续目标保持暂停，需主动恢复。

::: warning 中断后不会自动派发
已接受的待发请求会持久保存；进程重启后转为待确认恢复，而不是自动发送。主动停止全部任务或确认放弃会取消相应待发请求。尚未成功保存的输入不算已接受，请留意保存失败提示。
:::

## 回复与工具卡片

AI 的正文与思考内容使用同一个打字机速度上限。在「设置 → 通用设置 → 偏好设置 → 打字机速度」可选 **30–350 字符/秒**，默认 30。界面会跟随到字速度，有积压时在所选上限内加快追赶。这只调节本地显示，不改变模型的 `tok/s` 或工具输出。

停在聊天底部时，新内容超出输入框上沿，列表才向下跟随。往上翻看历史会暂停跟随，滑回底部或点回到底部按钮即可继续。一次加载较多更早消息时，列表会在滚动停稳后补入历史，当前可见的消息仍留在原处。长回复已收到但还在逐字显示时，已显示的段落保持原位，不会因为下一个字又重新分段；代码块仍可高亮和复制。追加代码时保留同一块已显示的高亮，新尾文先显示后补上颜色；切换消息、语言或主题时不会沿用不兼容的旧高亮。较复杂的 Markdown 可能稍晚显示，回复完成统计仍等待最终正文到位。调整打字机速度后，后续播放采用新值；如需比较快慢，请观察新回复，已经收到的历史文字不会重新播放。

模型正常结束后，已经收到但尚未显示的正文和思考会在所选上限内匀速收尾，不会在结束时整段跳出。回复下方的用量、耗时、上下文占用圆环和操作按钮会等这条回复播放完、最终正文显示到位后一起出现，避免正文还在继续时先显示完成统计。打开历史或中途离开再回来时，已有内容直接显示，不从头重播；主动停止时可以直接显示已收到的全文，不必等待尾部播放。设置与备份规则见[偏好设置](/guide/general#打字机速度)。

消息区默认保留原来的布局：你发送的内容使用右侧「原版」气泡，下方标注发送时间；AI 默认采用**文档流**，回复直接铺在页面上。可在「设置 → 外观主题 → 聊天气泡」独立选择两侧样式：用户有 8 套预设，AI 可选文档流或相同的 8 套气泡；Markdown、长文分段和聊天字号设置照旧，详见[聊天气泡](/guide/appearance#聊天气泡)。

AI 的一整轮执行过程使用**任务折叠**归拢：

- **运行时逐条显示过程**：正文、思考与工具调用按发生顺序显示，不会把工具调用前的说明文字挪到工具后面。工具各占一条居中胶囊，不额外增加按批次展开的工具分组头。
- **整轮任务结束后才统一收起**：中间回复或首段正文到达都不会提前折叠过程。结束后将过程归为一条居中的摘要，保留工具调用次数、耗时和失败数，最终回答单独留在摘要下方。
- 点击完成后的过程摘要可以展开或收起；展开后仍是逐条工具胶囊，再点其中一条查看详情。展开过程不等于展开全部工具详情，也不会重新执行工具。
- 运行时手动打开某条工具详情，不会因中间正文到达而自动合上；整轮任务结束时统一收起过程，之后仍可手动打开。完成后的手动展开/收起选择会保持，切换会话或滚出屏幕再回来不重置。
- 打开较早的记录时，聊天只加载最近的一部分，滑到顶部才继续往前补。若正好从某一轮中间开始，最上面那一截过程也会归入摘要；往前补到这一轮起点后，会并回该轮过程。缺少完整计时信息时不推测耗时。
- 过程内容按可见范围渲染，向下滚动即可继续查看；向上加载更早的记录时，已展开的过程和当前阅读位置会保持。
- 如果这一轮 AI 一次回答完、既没有思考也没有工具调用，则不显示过程摘要。

**你发出去的每条消息**下方常驻发送时间与「复制 / 回退 / 更多」按钮，可随时复制或回退其中某一条。**每个已结束用户轮的最终 AI 正文下方都保留操作行**，历史轮次也可以复制或打开更多选项；一轮任务中的中间回复不重复挂按钮。每轮的输入 token、输出 token、缓存命中率和耗时仍按轮合计，在复制后、更多选项前显示上下文占用圆环与百分比，两种统计口径不同，详见[回复下方的用量与耗时](#回复下方的用量与耗时)。

AI 的思考过程另外占一行，**默认收起**，可在[偏好设置](/guide/general#思考自动展开)开启「思考自动展开」。收起时显示思考图标、状态与耗时；点这一行展开查看内容，再点收起。正文开始输出或开始准备工具调用时，思考状态变为「思考完成」，耗时停止增加，不包含后续正文生成时间。展开后的思考内容在限高窗口里按段显示，长内容可以在窗口内上下滚动查看。手动展开或收起的选择会保持，思考结束并转入工具调用、滚出屏幕后再回来或切换页面不会重置；新一段思考的初始状态遵循偏好；未开启时仍默认收起。最近查看的 32 个已保存思考窗口会在当前进程内保留滚动位置，同一次浏览中流式思考转成历史消息时沿用当前位置；不同会话互不混用。进程重启、较早窗口超出保留范围，或离开时思考尚未保存为消息，滚动位置可能回到顶部。展开窗口内双击可收起，内容继续增长时也可操作。长按内容可选中文字并复制；长思考按可见段落组合，复制的是当前选区，不是整段全文复制。

等待模型响应时，消息区底部显示一行状态：一条白色高光往复地从这行文字上划过，后面跟着三个跳动的点（点不参与高光）。模型正在准备某次工具调用时（工具名先到、参数还在传输，可能需要数秒），这行文案会直接说明将要执行的操作，而不是一直显示「正在思考」——例如 `正在编辑文件`、`正在执行命令`、`正在联网搜索`。此时思考内容和耗时可能已经停止变化，这是思考阶段结束、正在生成工具参数；底部仍会显示对应的动态状态提示，即使上方还保留着思考或正文，也不会出现整段等待没有反馈的情况。

工具调用按独立的**居中胶囊列表**逐条呈现：

- **胶囊与内部内容整体居中**：每条显示工具图标、动作标题、耗时或状态，以及可点开的箭头。收起时采用更紧凑的高度，保留原有字号与行间留白；系统字体放大后可自然增高，不把文字强行压进固定高度。连续调用同样逐条显示，不按批次另套一层折叠头；贴底自动跟随时，新出现的胶囊会淡入并轻微纵向移入，标题与整条胶囊保持原尺寸，历史记录和已存在的胶囊不会因列表重组或分组移动重复播放；「过程列表可见」不代表「详情已展开」。
- **动作标题随本次调用一起给出**：当前会话的主模型在生成每次内置工具调用时，同时写出本次动作与对象，使用你的语言、最多 48 个 Unicode 码点；不是工具名、原始命令，也不是「执行中」「已完成」等状态。参数尚未收齐或没有可用标题时，可显示「读取文件」「执行命令」「执行工具操作」等通用动作，不用本地规则猜测复杂命令的用途。MCP 扩展工具保持服务端原有参数定义，不额外要求它们提供这个展示标题；原工具名、指令和参数仍可在详情中核对。
- **图标区分执行结果**：运行中使用主题主色，成功为绿色，失败为红色；未执行保持对应状态，不显示为成功。运行中的调用不计入失败数，标题内容也不决定结果颜色。
- **单条耗时只计真实执行**：等待审批、等待同一文件的其他操作释放占用或尚未开始执行的排队时间，不算进工具耗时。并行调用各自更新输出并独立计时，完成后立即停止计时，不必等最慢的一条。计时使用独立的固定宽度区域与等宽数字，秒数增长或切换成分、小时格式时不会挤动标题；长标题保留单行省略。不足 100 毫秒显示 `<0.1s`，不会被四舍五入成 `0.0s`。没有实测计时的旧记录显示 `—`，不根据消息保存时间或工具条数推测。自动贴底滚动不会触发输入区的用户滚动淡化效果。
- **单条详情默认收起**：运行时可随时点胶囊或箭头查看「指令」与「执行结果」，再点收起；长按消息中的工具胶囊可打开[工具预览详情](#工具状态条与预览)。首段正文、中间说明或同轮后续工具到达，都不会触发整轮过程提前折叠；整轮任务结束才收成上文的过程摘要，之后可重新展开列表并点开单条详情。
- 较大的工具结果会在后台整理，展开后可能稍等片刻才显示可查看的内容。内容过长时在一个固定高度的窗口里上下滚动查看，底部渐隐提示下方还有内容。单条详情的手动展开/收起会被记住，划走再划回来不会自动合上。工具仍在输出时，在窗口内滚动会暂时固定正在浏览的内容，避免新输出替换文字导致跳动；滚回窗口底部并停止滚动后恢复实时更新。浏览期间工具仍会继续执行，外层聊天不会自动滚动抢走位置。工具和思考窗口内，按住拖动到顶部或底部后继续拖动，可以带动外层聊天列表；快速滑动并松手后，窗口的惯性滚动到边界即停止，不会带动外层列表。
- 改动文件的工具（写文件、改文件）展开后是一张**差异卡**：左上角是文件路径，右上角「复制」可复制这段差异，正文是带行号的 `+ / −` 彩色差异，底部汇总本次改动（如 `+3 −0 · 1 个文件`）。

**标题与模型用量**：标题随正常的内置工具调用一起返回，不再另发标题生成请求，也不为此另传参数摘要、图片、工具结果或完整历史。标题文字仍属于正常模型请求的 token 用量，不表示所有请求总用量完全不变；也不会为标题引入新的服务商。

**标题不是结果或许可**：它只帮助理解这次调用的意图，不证明工具已经成功、操作安全或获得批准。真实执行、禁止规则、Root 与高危操作的审批边界均不改变；审批时仍须核对原始工具、命令和目标，不能把标题作为批准凭据。成功绿色、失败红色仍取决于实际执行状态，不取决于标题内容。

已生成的动作标题随聊天记录保存，重启后保留，并随聊天历史备份与还原。旧记录没有标题时继续使用通用动作，不会为补齐旧标题自动请求模型；需要确认具体操作时，请展开原指令、参数与执行结果。

后台任务、子代理结果、主会话与子代理之间的消息，以及执行中的用户补充，会在聊天列表中显示为独立通知行，不再嵌在工具卡片内。通知行按发生时间排列，并归入所属轮次的任务过程；轮次收起时，通知随过程一同收起，展开后可在原时序位置查看。贴底跟随时，后续工具或回复出现会把此前的通知一起向上滚动。空会话收到通知时也会显示通知列表。当前加载历史范围之外且无法关联到消息的旧通知不会单独堆到列表顶部。用户补充行保留原始文本，不会再重复显示同一条用户消息。通知已送达的提示不等于新增用户请求，也不会单独新增子代理卡片；当前轮若因计划被拒绝或未获有效批准而结束，不会用待处理提醒自动续跑。

后台任务通知将任务名称和执行结果分开显示：名称最多两行，时间独立保留；下面完整显示完成、失败或中断状态与退出码。未知退出码显示为未知，不把它当作 0。长名称省略不会隐藏退出码，字号放大或窄屏时卡片可增高，不使用空白副行占位。

代理通知使用单行标题与单行摘要，标题为“代理名称发来一条消息”，名称只显示一次，时间保留在行尾；完成、失败或停止结果保留在摘要中。卡片之间留白与工具胶囊一致，长标题和摘要省略展示，不因压缩卡片而改变原始消息与任务状态。

## 子代理协作卡片

主会话会按**你实际发送消息的轮次**归拢子代理协作任务。每轮的协作分组默认收起，点开后展示该轮涉及的全部子代理，不固定截成 3 张或 5 张；同时运行最多 5 个是并发限制，不是卡片上限。

- **位置与合并**：历史分组位于所属轮的正文、工具等内容之后、下一条用户消息之前；主会话当前仍在工作时，本轮分组位于实时正文与思考之后。旧轮子代理仍在运行也不会移到新轮。同轮同一个子代理只显示一张，后续轮次真实追加指令时可另有卡片；仅收到后台提醒不增加卡片或用户轮次。
- **展开概览与状态**：展开首标题栏显示“工作代理”和“已完成代理”数量，排队、执行中、等待确认计入工作，失败和中断不算完成。展开列表中代理名称、任务标题、状态分列显示；状态固定在行尾，长任务标题单行省略，不挤掉状态。窄屏或放大字体导致同一行放不下时，任务标题另起一行，状态必要时换行完整显示，不缩小字体。收起时保留头像和当前活动摘要。
- **稳定排序**：已完成在前，失败、中断、已删除和仅有历史记录的任务居中，排队、执行中和等待确认在后；同类保持原顺序，不因计时或输出刷新反复跳动。
- **真实名称**：分组收起时也会显示参与者名称摘要；点开后，每张卡片以实际派发的代理名称为主标题，任务描述放下一行，侧边栏的子会话也采用同样层级。例如实际配置叫「编码员」或「审核员」就显示对应名称，实际选用 Explore 就保留 Explore；不会用任务内容或模型名猜角色。历史没有名称时会提示「名称未记录」，未指定命名代理时仍显示「子代理」。
- **两层展开**：子卡片也默认收起，摘要显示身份、任务、状态、往返次数、工具调用数和耗时。点卡头查看主代理、子代理和你的交互记录，可向较早或较新翻页；「执行过程」另外展开，不自动打开全部工具详情，也不展示子代理私有思考。只在展开且界面前台可见时加载对应正文，收起或离开后停止加载，不停止真实任务。
- **结束时收起子卡片**：排队、执行中或等待确认转为完成、失败、中断或删除时，对应子卡片自动收起，整个协作分组不会被强制收起；结束后仍可手动重新打开。
- **操作与确认**：展开后可进入或停止对应子会话；等待确认时，入口只带你进入子会话审阅完整请求，卡片不能快捷批准。补充指令只发送给对应子代理，使用它的正常用户消息队列，不是后台代理通知，也不覆盖主会话草稿；以 `/` 开头的内容同样作为普通正文发送，不会触发主会话的斜杠命令。卡片来源的排队指令只能排序或删除，不能编辑或立即插入，要改内容请先删再发。已删除、不属于当前主会话或工作区不一致的目标不能发送。

能明确对应到本主会话任务的成功派发信息由协作卡片承接，避免重复显示旧派发提示；失败、未识别、部分成功或带警告的信息仍保留。删除子会话后，主会话保留已保存的往来并标为已删除；删除主会话会一并清理所属交互记录。重启或恢复备份只展示已有历史，不会自动重放尚未开始的补充指令。

详细操作见[子代理协作卡片](/guide/subagent#主会话中的协作卡片)，保存与恢复范围见[子代理交互记录备份](/guide/backup#子代理交互记录)。Root、计划审批与任务待办的规则不因卡片变化而改变。

## 工具状态条与预览

当前会话有工具记录时，输入框上方会显示工具状态条，方便在不反复滚动聊天的情况下查看动作与结果。它覆盖**当前会话全部未被上下文压缩的工具**，不只显示正在执行的这一轮；不会把其他会话或子代理内部的工具混在一起。子代理内部操作可从[协作卡片](#子代理协作卡片)独立展开「执行过程」，也可进入对应子会话查看。

### 翻页与查看详情

- 默认**跟随最新活动**；点击左右箭头逐项查看，长按左箭头跳到第一项，长按右箭头跳到最后一项，页码显示当前位置与工具总数。状态条动作标题在避开缩略图和翻页按钮的区域内居中；同次调用更新参数或从准备转为执行时，不反复清空标题和预览。
- 手动翻页后会留在选中的工具，新调用或新输出不会把你抢回最新项；切换会话后重新自动跟随。只有一项工具时不显示翻页按钮。
- 状态条的动作标题在状态图标与翻页按钮之间的可用空间内居中；长标题省略显示，仍以同一空间为中心，不另为分页宽度留一份空位。窄屏、大字体或页数较多时，紧凑页码会单行省略，给标题保留显示空间；两侧翻页箭头尺寸和操作不变，无障碍文本与详情仍保留完整页码。
- 点状态条标题或缩略图可以打开详情；也可以长按聊天过程中的工具胶囊。同一条工具的安全预览已经就绪时，详情直接接续该内容；首次查看尚未整理的结果时会短暂显示加载提示。详情与状态条独立选页：打开详情不会停止状态条的自动跟随，详情底部翻页也不会改变状态条已经选中的项。打开和翻页都只是查看，不会重跑工具或代替审批。
- 手机详情采用较高的底部抽屉，宽屏采用居中弹窗：顶部为居中动作标题、关闭与复制，下面显示实际执行状态；普通工具用黑底等宽内容区展示安全整理后的命令、输出、参数或红绿差异，task 操作使用专门的子代理详情。正文可上下滚动，底部可逐项翻页。手机正文滚到顶部后，继续向下拖可关闭；也可点左上角关闭按钮，底栏会先完成退场再收起，不会突然消失。长按选择文字后的拖动用于选区，不作为关闭手势。
- 手指接触详情、拖动、惯性滚动或底栏关闭／回弹期间，正文和图像暂时保持已显示的画面，避免实时输出刷新与操作争用；松手且界面稳定后再显示最新内容。首次内容可在底栏展开时整理，普通工具的长输出分块按需排版。长按选择针对已加载的文字；要复制完整的安全预览，可点顶部复制按钮，或在长按菜单选择「复制安全展示内容」。真实工具仍继续执行，敏感内容和文件所属环境的隔离不等待手势结束。
- 显示与复制使用同一份安全内容，不是未脱敏原文查看器。敏感字段、文件正文与输出可被隐藏或截断；有结果时优先展示结果，不保证同时逐项列出全部参数。准备阶段只显示尚未执行的草稿。要核对原始调用，可回到聊天工具记录；长结果提供完整文件路径时，可按需打开。

### 缩略图与参数草稿

缩略预览默认开启。长按状态条标题，可打开启停预览菜单；长按缩略图可关闭预览。选择仅保存在本机、不随应用设置备份。关闭缩略图不关闭状态条或详情，更不会停止真实工具；相关说明见[工具缩略预览](/guide/general#工具缩略预览)。

- **指令、结果与差异**：根据工具已有内容生成有界的文字或文件差异预览。同一次调用的参数和阶段更新时，已显示的预览会保留到新内容准备好，不反复清空再显示；切换调用、会话或敏感内容边界时不会借用上一项。敏感内容在缩略图、详情与复制中采用一致的安全投影，不能靠打开详情绕过隐藏，不将摘要当作真实执行结果的替代品。
- **正在准备的参数**：模型已传来部分工具参数时，可看到已收到的参数草稿；这是累计内容的展示快照，不是已执行指令或已落盘文件。草稿显示有上限，不为了预览截断真实调用，也不会从草稿触发执行；没有参数流时不会假造逐字过程。
- **浏览器画面**：只轻量观察工具已经明确关联的现有标签页，页面变化类动作运行时可刷新画面；失败时保留该次调用的上一帧，不借别的调用或页面冒充。已完成截图优先展示它自己的图片，详情可独立加载更清晰的图，不受缩略开关影响。不会为了预览创建、导航或切换标签，也不会额外调用截图工具或上传画面。
- **工具返回的图片**：可显示工具本来就已返回的图片，以及当前环境中可读的既有图片。本地缓存与 SSH 文件分开读取；切换会话、项目或连接后，旧的读取结果不能贴到新任务上。缓存有大小上限，图片已清理或无法访问时退回文字，而不是重新执行工具。
- **命令资源信息**：命令真实运行且缩略图可见时，底部显示 App 进程的 CPU 与内存采样；这不是每条命令独占的消耗，也不是 SSH 服务器的 CPU 或内存。准备阶段、工具完成、缩略图关闭或聊天不可见时不继续采样。

这些预览只位于 App 内聊天区，不是系统悬浮窗，不需要悬浮窗权限，也不额外向模型或第三方上传内容。聊天区不可见、被其他页面遮住或 App 切到后台时，停止预览采样与缩略刷新；实际工具、已有浏览器页面和后台任务按原来的流程继续，不因预览隐藏而停止。

## 全屏看图

聊天里的图片都可以点开查看大图，四个位置一致：

- 输入框上方待发送的图片附件；
- 已发出的消息气泡里的图片附件；
- AI 回复正文里显示出来的图片（AI 生成的图表、截图，或它从工作区读取的图）；
- AI 用发送工具（或图片生成）发给你的图片。

全屏之后：双指捏合放大、放大后单指拖动查看细节、双击在原图和放大之间来回切换。点画面、按返回键或点右上角的 × 关闭（放大状态下点画面不会关闭，避免查看细节时误触）。平板上无论聊天区占半屏还是全屏，大图都铺满整个屏幕。

图片文件被移动或删除后无法打开，会提示「图片加载失败」。GIF 只显示第一帧。

## AI 发来的文件

AI 用 `sendFile` 发来的文件（以及它生成的图片）在聊天区**一个文件一行**：左边是缩略图或类型图标，中间是文件名与「大小 · 路径」，右边有 `›` 提示可点。

- 点图片行 → 应用内全屏看图；点其它类型 → 交给系统对应的 app 打开（安装包会先确认「允许安装未知应用」）。
- 文件被移动或删除后点开会提示「文件不存在或已被移动」；所在位置不支持分享给其它应用时会给出对应说明。用「添加外部工作区」加进来的外部工作区、自定义镜像里挂载进来的目录，其中的文件同样可以点开。
- 每行排在发出这个文件的工具调用**所在位置**，因此翻记录时能看清「AI 是在哪一步发来的这份文件」；文件行可直接点击，不必先展开工具详情。
- 一次调用最多 10 个文件、单个文件大小上限默认 100MB（可在「偏好设置 → 工具」调整）；只要有一个不存在或超限，整批都不发，AI 会收到失败原因并修正后重试。

## 回复下方的用量与耗时

每个已结束用户轮的最终 AI 正文下方都有一行信息，按「输入 token → 输出 token → 缓存命中率 → 耗时 → 复制 → 上下文占用圆环与百分比 → 更多选项」排列；圆环位于复制之后、更多之前，可点击打开详情。正在生成的轮次和中间步骤不重复显示这行；有些统计项会因上游未提供数据而不显示。

- **token 用量**：`↑` 是本轮的输入 token、`↓` 是输出 token。一轮任务里模型可能被调用多次（每次工具调用都会再请求一次），这里是这一轮所有请求的总和，不是某一步的数字。
- **缓存命中率**（**1.11.0 起**）：数据库图标旁的百分比，是本轮命中服务端缓存的输入占本轮总输入的比例。命中越高越便宜也越快。未命中缓存、或渠道不返回缓存数据时不显示。该字段从 1.11.0 开始记录，旧消息看不到。
- **本轮总耗时**：时钟图标旁的时间，只挂在一轮任务的最后一条回复下。从应用实际开始处理这条用户请求算到本轮结束，包含模型等待、工具执行和等待你审批的时间，**不含消息在待发送队列中的排队时间**。处理中收到后台任务或子代理完成提醒，不会把当前用户轮切成另一轮重新计时。完成后保存这次实测时长，重启、切换会话或恢复聊天备份后仍使用已保存值；旧记录没有实测时长时显示 `—`，不根据消息时间戳补算。不足 100 毫秒显示 `<0.1s`，不是 `0.0s`；更长时按秒、分或小时展示。

以上 token、缓存与耗时保留「本轮合计」口径。整个会话、整个渠道的累计用量与缓存命中率在[Token 用量统计](/guide/token-stats)里看。

### 上下文占用

圆环表示**该轮最终回复所对应的那次模型调用，输入占当时可用输入预算的比例**。分母与自动压缩采用相同口径：为输出预留空间，并考虑模型的输入上限，不直接拿原始上下文窗口计算。它不是本轮多次调用的累计 token，更不是累计费用或输出进度。

- **有真实输入用量**：优先使用上游返回的输入 token 数。
- **没有返回用量**：使用经已有真实用量校准的上下文估算，百分比前带 `≈`；没有可用校准基线时仍为估算值。
- **历史快照**：每条回复保存当次输入量、有效输入预算、是否估算，以及当时已记录的分项。以后切换模型、修改窗口或压缩上下文，都不会重算旧回复的百分比或分项。旧消息没有占用快照时显示 `—%`，不把未知用量当作 0%；缺少分项则显示「未记录」。随聊天历史备份时会保留已有快照，见[备份与还原](/guide/backup#聊天历史中的上下文快照)。
- **颜色**：小于 50% 为绿色，50% 到不足 85% 为橙色，达到 85% 为红色。颜色用于提示占用程度，不代表请求一定成功或失败。

### 点击圆环查看详情

点击圆环会打开适配手机与平板的底部详情面板，查看该轮最终模型调用的输入总量与当时的**有效输入预算**，以及五个本地估算分项：

- **系统提示词**：发送给模型的系统说明。
- **工具定义**：模型可调用工具的说明与参数定义。
- **聊天历史**：用户和 AI 的历史消息等文本内容。
- **工具结果**：工具返回给模型的内容。
- **图片**：上下文中图片的估算占用。

分项用于帮助判断空间主要花在哪里，不是供应商精确拆账；本地估算的分项之和不保证等于供应商报告的输入总量。旧消息可能已有总量而没有分项，这时分项显示「未记录」，不会用当前模型补算。面板中的手动压缩按钮作用于当前会话完整上下文，规则见[上下文用量与压缩](#上下文用量与压缩)。

## 长会话与显示缓存

历史、Markdown、代码高亮、公式与图片使用有大小预算的显示缓存，避免切换多个长会话后一直保留全部副本。缓存淘汰不会删除聊天记录、工具结果或图片原文件，也不会缩短发给模型的上下文；再次查看可能需要重新解析或读取。

相同内容会尽量共享解析和图片读取，页面不再使用的展示计算会及时结束；已显示的内容仍保持有效。图片和公式的清晰度、聊天分页与原文查看能力不因缓存预算降低。实际占用还受正在显示的内容、WebView、终端、任务并发和设备运行时影响，缓存预算不等于整个 App 的内存硬上限。

## 聊天背景与字号

在「设置 → 外观主题」二级页面中，可以分别调整全局背景与仅聊天内容区使用的背景，也可以把聊天字号设为 80%–140%（默认 100%），并独立选择用户与 AI 的聊天气泡。字号同步影响 AI 正文、用户消息、思考内容与 Markdown 代码，不改变菜单和按钮字体；调整时可先看预览，选择气泡也不改变这些缩放与 Markdown 行为。详见[外观与语言](/guide/appearance)。
