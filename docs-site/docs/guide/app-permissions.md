# 软件权限

「设置 → 软件权限」集中管理 App 需要的系统级权限与本机 Root 总开关。系统权限状态在页面恢复时（包括从系统设置页返回）自动刷新，已授权的状态项点击后不会有反应；Root 是可以主动开关的独立设置。

后台保活、屏幕常亮、AI 完成通知、实时通知、授权审批通知这几个开关在[后台运行](/guide/background-run)页。

## 安装未知应用

显示当前是否已允许。未允许时点这一行会跳到系统设置里本应用的「安装未知应用」开关页，开启后才能安装 APK。

## 访问存储空间

显示当前是否已授权。未授权时点击会弹系统权限申请框，用于读写工作区文件与容器镜像。

如果权限已被永久拒绝（系统不再弹框），会有弹窗提示，点「去设置」手动开启。

## 忽略电池优化

显示当前是否已豁免。未允许时点击跳到系统的电池优化申请页，对本应用豁免省电策略，降低后台进程被杀的概率。

## 自启动管理

点击跳转到你设备厂商（小米、华为、OPPO、vivo、魅族等）的自启动管理设置页，允许 App 在开机或被系统终止后自动拉起。厂商设置页打不开或匹配不到厂商时，会回退到本应用的详情页。

这一项配合「后台运行保活」和「忽略电池优化」一起使用，能进一步降低后台被终止的概率——国产 ROM 的后台限制比较激进，若长任务经常被打断，建议三项都开启。

## Shizuku 授权

Shizuku 让本应用可以执行系统命令，是 AI 的 `Shizuku` 工具的前提。这一行显示当前状态：

- **未安装 / 服务未运行**：点击打开 Shizuku 应用，按其中的指引安装或启动服务。
- **未授权**：点击申请授权，在 Shizuku 弹出的授权框里选「允许」。
- **身份待确认**：已授权，但暂时无法读取服务身份。点击重试，或打开 Shizuku 核对服务并重新连接；身份未确认时不执行命令，也不会显示为 Root 已就绪。
- **身份不受支持**：服务身份不属于 ADB shell 或 Root，请在 Shizuku 中核对启动方式后重新连接。
- **已就绪**：服务为 ADB shell 且系统授权完成。
- **Root 已就绪**：服务为 Root 且系统授权完成，AI 可申请执行 Root 命令。

需要 Root 启动时，手机须已有 root，由你在 Shizuku 应用中选择 Root 启动并授权本 App；阿九工作台不代为启动外部 Shizuku 的 Root 服务。从 Shizuku 返回本页时状态自动刷新，未授权时会先提供申请入口，获准后才确认身份。

系统授权不等于聊天工具授权：普通调用可选择「拒绝」「仅本次允许」「本会话始终允许」。记住的范围只适用于当前会话、服务身份和连接；ADB shell 与 Root 分别授权，服务重启、断开、切换身份或撤销系统授权后须重新确认，不与独立 Root 工具共用。ADB shell 下不能通过显式 `su`/`sudo` 提权；禁止规则始终优先，高危命令必须单次确认，没有「始终允许」。用法与排错见 [Shizuku 工具](/guide/shizuku)。

## Root 总开关

**默认关闭**。仅当手机已经取得 root、且系统 su 管理器允许本应用执行时，才可能使用独立的宿主 `Root` 工具；开启本页开关不会为未 root 的手机取得 root，也不提供 root 安装或漏洞利用。

- 开启后，普通 Root 调用可选择「拒绝」「仅本次允许」「本会话始终允许」。记住后，同一会话、同一本机启用周期的普通调用无需重复弹窗；高危命令仍只可拒绝或仅本次允许，项目/全局禁止规则始终优先。
- 每条命令仍核对完整内容与当前授权状态，只取得本次执行许可，防止替换命令或重复使用。
- 关闭会撤销待审批请求与未使用的执行许可，使本次启用周期的会话授权失效，并终止本应用管理中的 Root 进程。再次开启须重新授权。
- 关闭不等于回滚，无法撤销已经完成的修改，也不保证终止任意脱离本应用管理的后台进程。
- 开关与本机授权身份不随 App 备份迁移，其他设备恢复不能继承 Root 会话授权。该开关只控制独立 Root 工具，与容器/SSH 的 `sudo`、Shizuku 的启动及系统授权分别管理，两种宿主通道的会话授权也不共用。

Root 输出有长度上限，不会自动归档到当前 SSH 服务器，但**作为任务结果仍会交给你已选择的 AI 服务商**。执行前请确认命令范围和可能读取的敏感数据；完整授权边界见 [Root 工具](/guide/permissions#root-工具)。
