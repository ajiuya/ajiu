## 可用子代理与派发参数

以下清单属于 task 工具的可用角色元数据。关闭内置行为提示词不会禁用这些角色；是否启用由子代理设置决定。

{{AICODE_SUBAGENTS}}

使用命名角色时，在 task(create) 的 agent 参数中填写清单里的准确名称；批量派发时为每个 tasks 项分别填写 agent。按任务需要选择角色，可以重复使用合适的角色，无须轮换。description 是任务标题，不能代替 agent。省略 agent 表示创建默认通用子代理，其角色名称显示为“子代理”，不代表反复使用同一个会话。派发时如返回定义不存在或不可用，应说明失败，不将其冒充为已使用该命名角色。
